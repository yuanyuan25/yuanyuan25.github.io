Agent Memory Distillation: Empowering Small LLM Agents with Hierarchical Teacher Memory
arXiv:2608.07169
创新点
提出 training-free 的 Agent Memory Distillation（AMD），把大模型 teacher 的成功轨迹蒸馏为三层互补记忆——Workflow（任务级策略）、Subtask（中间粒度行为示例）、Function（单函数调用约定与常见坑）——并配以差异化注入机制：前两者在任务开始时主动注入，Function 记忆在工具调用报错时反应式检索。区别于以往端到端蒸馏，AMD 完全不更新学生模型参数。
结论
以 GPT-5-mini 为 teacher、4B–8B 四款学生模型在三个工具使用基准上平均提升 27.2%p（AppWorld）、11.2%p（BFCL V3）、3.4%p（ToolSandbox），并一致超越已有 memory-based 基线。Subtask 记忆贡献最大，teacher 效果取决于其能力与学生兼容性，4B 小模型受益最多。
结论支撑
在 AppWorld、BFCL V3、ToolSandbox 三个公认工具调用基准上以四款 4B–8B 学生模型系统评估，含消融（各层记忆贡献）与 teacher/学生兼容性分析，实验设计较完整。增益随基准难度递减（ToolSandbox 仅 +3.4%p），说明方法在复杂多轮场景边际收益有限，结论克制可信。
局限性
仅验证 4B–8B 小规模学生与单一 teacher（GPT-5-mini），更大模型或自蒸馏场景未覆盖；对 ToolSandbox 这类复杂交互基准提升微弱；记忆质量完全依赖 teacher 成功轨迹的获取，冷启动场景下适用性存疑；长期记忆污染与过时问题未讨论。
点评与适用范围
适合部署端侧/低成本小模型 agent 的团队直接借鉴：无需训练、实现门槛低（记忆构建+检索注入），收益明确。对工具调用密集但轨迹成功率低的业务场景尤其划算。建议优先复现 Subtask 记忆部分，其贡献最大且构造最简单。
AI4AI at Test-Time: Strong-to-Weak Capability Transfer via Harnesses
arXiv:2608.12307
创新点
提出 test-time 的 strong-to-weak capability transfer：不更新弱模型参数，而是由强 builder 模型为其构建 inference-time harness（确定性代码、benchmark-specific routing、严格答案格式约束），将认知结构以工程脚手架形式下沉，区别于 teacher forcing、on-policy distillation 等训练时方法。
结论
在 4 个 Theory-of-Mind benchmark 上，harness 使弱模型平均表现从 0.49 近乎翻倍至 0.91；收益主要来自把不稳定推理卸载到确定性代码与路由，而非让弱模型推理更多或采样更广；builder 推理强度与 harness 质量单调正相关，越弱的 target 收益越大。
结论支撑
实验设计较严谨：builder 仅用 5% 数据作 validation 迭代多轮，再在完整测试集评估，避免了过拟合测试集。消融指出收益来源是代码化与格式强制而非推理扩展，结论可信。局限是只在 Theory-of-Mind 这类结构化任务上验证。
局限性
仅在 4 个 Theory-of-Mind benchmark 上验证，任务类型单一；harness 是 benchmark-specific 的，泛化到开放任务的能力未验证；未讨论构建 harness 的推理成本与收益比。
点评与适用范围
对做 agent 工程化的团队有直接借鉴：与其追求模型更强，不如让强模型为线上弱模型写 harness，落地门槛低、无需训练。适合推理预算受限、任务格式固定的场景。
AutoDesign: Meta-Harness Optimization for Long-Horizon Agentic Design
arXiv:2608.13560
创新点
将结构化媒体生成建模为以 model-harness 系统为中心的长程 agentic 过程，并提出 meta-harness optimizer：由元优化器基于 rollout 反馈递归改进 code agent 的 harness（脚手架/工作流），实现对齐人类设计先验的自我进化。区别于静态 harness 范式，AutoDesign 让 harness 本身成为可学习对象，并提出 paper-to-poster 评测集 PosterBench（100 篇主赛道 + 10 篇 mini 对照子集）。
结论
在 PosterBench 主赛道取得 78.32 的最高分，超过闭源商用系统 Claude Design 7.45 分；七种 code-agent-model 配置下集成学到的 DesignHarness 将平均分从 54.99 提升至 67.39（+12.4%）；全自主长程循环可在 40 分钟内执行 253 次工具调用、11 轮编辑，成本低于 3 美元，达到人类评估的平均会议海报质量，且在盲测人评中偏好最高。
结论支撑
评测设计较扎实：自建 100 篇跨五学科的 PosterBench + 10 篇对照子集，七种 agent-model 配置的一致性提升（+12.4%）说明 harness 增益不绑定特定底座；含成本与效率数据（40 分钟、<$3）及 system-blind 人类偏好研究。不足在于 PosterBench 为作者自建基准，评分标准可能存在利于自身方法的设计偏向，外部复现待观察。
局限性
仅在 paper-to-poster 单一任务上验证，meta-harness 优化对其他长程设计任务（如网页、幻灯片）的泛化性未知；评测基准自建，与通用 agent 基准的可比性有限；递归自我改进的收敛性与稳定性（是否会过拟合 rollout 反馈）未讨论；运行成本虽低但依赖强 code agent 底座。
点评与适用范围
对做 agent 工程化的团队启发大：'优化 harness 而非优化模型'是低成本高收益的路线，meta-optimizer + rollout feedback 的递归改进框架可迁移到任何 code agent 驱动的生成任务。落地门槛中等，核心是设计好评测反馈信号。做自动化内容生产（海报、报告、幻灯片）的团队可直接跟进。
Business Arena: Benchmarking LLM Agents in a Realistic Marketplace
arXiv:2608.08621
创新点
把 agent 评测从短任务推向长周期商业经营：agent 在基于真实采购数据与权威市场校准的仿真环境中经营跨境店铺，长时 horizon 内买卖决策后果延迟且耦合。评测方法论上不止看利润——用人类设计策略估计机会上限、skill-level 指标拆解能力结构、action-level 归因追踪盈亏来源，并用 mechanism ablation 排除模拟器捷径。
结论
15 个前沿模型的最终净资产均值相差 9 倍；即使是最好的模型也落后于人类设计的策略，说明商业经营对 LLM agent 仍是难题。技能分析还区分出溢价卖家、高周转批发商、客服专家等不同经营风格。
结论支撑
评估设计较严谨：mechanism ablation 验证成绩反映真实商业智能而非钻模拟器空子，human strategy 基线提供机会上限参照，action-level attribution 使利润可解释。15 个模型的规模也可观。潜在弱点是人类策略基线的设计质量决定"差距"结论的强度。
局限性
单一跨境零售场景，结论能否推广到其他商业形态未知；仿真市场与真实经济的保真度差距无法消除；人类策略基线本身的设计水平会影响"落后人类"结论的解读；未涉及多 agent 竞争博弈。
点评与适用范围
适合 agent 评测与决策智能方向的团队，skill-level 指标 + action-level 归因的评测框架设计值得借鉴到任何长 horizon agent benchmark。对做自动化运营、电商 agent 的团队有直接参考价值。作为 benchmark 使用门槛低，等开源即可接入。
Can LLM Agents Stick to the Script? A Benchmark for Long-Horizon Consistency in Interactive Narratives
arXiv:2608.08160
创新点
将交互叙事中的长程逻辑一致性问题形式化为 Narrative Commitment Preservation（NCP），并构建 NCP-Bench：100 个源自电影梗概的叙事环境，每个含结构化叙事规范（trajectory、commitments、initial facts），可在 player agent 与 narrator agent 的交互全程自动校验。相比通用长上下文评测，它专门针对无约束用户干预下的叙事完整性。
结论
前沿 LLM 存在显著的长程一致性缺口：语言质量高不保证 commitment 保持。最强模型 GPT-5.2 在 20 轮后存活率仅 42%，各模型事实冲突率在 40%–68% 之间，且只有个别运行能在 100 轮限制内满足全部 achievement commitments。
结论支撑
结构化叙事规范支持自动校验，避免了纯 LLM-as-Judge 的主观性；对抗性干预设置直接压力测试一致性而非流畅度，设计针对性强。数字具体（42% 存活率、40–68% 冲突率），结论可信。不足是 100 个环境规模偏小，电影梗概衍生的叙事类型代表性有限。
局限性
仅 100 个叙事环境，且均源自电影梗概，题材多样性受限；自动校验依赖结构化规范的可解析性，对开放生成内容的覆盖可能不全；未考察记忆增强、状态追踪等缓解手段，只停留在暴露问题层面。
点评与适用范围
AI 游戏、互动叙事、角色扮演 agent 团队必看：NCP 的形式化方式可直接移植为长程 agent 一致性评测（任务状态、用户承诺、事实记忆）。也提醒做长程 agent 的团队：当前模型在对抗干预下的事实一致性远未解决，落地需外挂状态追踪。
Co-Evolution in Agentic Systems: Toward Self-Directed Evolution Beyond Human Design
arXiv:2608.10299
创新点
综述 agentic 系统中的 co-evolution：多个 agent 与环境相互施加适应压力的多组件自演化。提出渐进三阶段分类法刻画系统如何逐步摆脱人类工程约束——Agent-Agent 共演化（对抗/协作/组织适应）、Agent-Environment 共演化（任务、反馈、交互空间随 agent 变化）、Meta Co-Evolution（演化机制本身可演化）。
结论
单体自演化受限于静态学习上下文（固定任务与反馈），共演化是突破路径。论文系统梳理了三阶段研究版图，并指出评估此类系统、跨多组件扩展、以及让日益自主的演化过程保持安全可控是当前开放的挑战。
结论支撑
作为综述，价值在分类法的组织力：三阶段递进框架把零散的 self-evolution、multi-agent 适应和环境演化工作纳入统一图景，并明确标注开放挑战。论证方式为文献归纳而非实验，合理但依赖选文的覆盖度；Meta Co-Evolution 一层目前文献稀薄，更多是前瞻性定位。
局限性
综述本身无实验贡献；'逐步摆脱人类约束'的三阶段划分带有较强叙事性，实际工作未必按此线性演进；安全可控只列为挑战未给方案；快速迭代领域中综述时效性风险高。
点评与适用范围
适合研究 agent 自演化、multi-agent 系统和 agent 安全的团队作为入门地图和选题参考，三阶段框架可直接用于组织内部技术调研。无落地成本，属阅读型论文；但想做实际系统的团队需自行补足框架下各方法的真实成熟度评估。
ComBodied Agents: a New Paradigm of Human-Centric Agentic AI
arXiv:2608.10915
创新点
指出 Digital Agents 只改软件状态、Embodied Agents 只改物理状态的结构性缺口，提出以'人的状态轨迹'为首要建模、干预和评估对象的 Combodied Agents 范式：事件化多模态感知 + 纵向可纠错记忆 + Personal World Models 预测干预后果 + 在同意、不确定性、安全和可逆性约束下选择适度支持的 admissible intervention policy，构成闭环。
结论
框架主张用目的受限、不确定性感知、用户可纠正的表征替代完整的 Human Digital Twin，并按 human-state 目标、关系情境和 agent 角色组织设计空间，提出场景化评估、agency-preservation 指标、边缘侧个人模型与治理方向，将 Agentic AI 从外部任务完成转向持续的人类受益。
结论支撑
属于立场/框架性论文（38 页、10 表），论证靠概念梳理与设计空间组织，辅以漏服药物等动机性场景说明，无系统实验。作为范式提案其逻辑自洽、组件边界清晰，但 Personal World Models 的预测可靠性、intervention policy 的可实现性均无实证，说服力停留在概念层。
局限性
无任何实验验证；人的状态建模依赖主观且难量化的 construct，评估指标仅停留在提案层面；隐私与同意机制只给方向未给方案；穿戴/机器人等感知通道的数据质量与噪声问题未讨论。
点评与适用范围
适合做个人助理、健康 agent、AI companion 的团队作为概念框架和对标清单使用，agency-preservation 指标和场景化评估思路值得借鉴。落地难度高：核心组件 Personal World Models 尚无可行的技术路线，短期宜只取'可纠错记忆 + 适度干预'两点的设计原则。
DarwinX: Evolving Agent Harnesses Through Natural Selection
arXiv:2608.07545
创新点
将 agent 自进化从单 lineage 搜索改为冻结模型下的 harness 种群选择：preserve-and-extand contract 只接纳扩展覆盖且不回退的变体，archive 保留多条 lineage 供重组，failure/teacher/self 三类证据共用一个编辑接口；fitness 直接取自各 benchmark 自带 verifier，无 gold solution、无人为挑选，避免局部收益导致其他任务回退。
结论
在四个递进隔离进化信号与测试的 benchmark 上，单轮进化平均提升约 17 分：Terminal-Bench 2.1 提升 7.7 至 83.2%（更强底座下达 84.7% 前沿水平）、TerminalWorld held-out 达 68.3% 超所有现成 agent、WebArena-Infinity 真实任务 pass@1 从 43.5% 升至 93.0%（audit-clean）；Terminal-Bench 进化出的 harness 可直接迁移至 SWE-bench Verified。
结论支撑
实验设计强调信号-测试隔离（held-out split、跨 benchmark 迁移、跨底座模型复现）以及 audit-clean 验证，较好支撑了'进化的是通用 agent 能力而非 benchmark 补丁'的核心主张；数字具体、迁移实验有说服力，方法学上比单点刷榜更扎实。
局限性
进化收益依赖各 benchmark verifier 的质量，verifier 有漏洞时选择压力会偏离；进化消耗大量 evaluation compute，摘要未给出成本-收益分析；主要在 coding/web agent 类任务验证，其他域未覆盖。
点评与适用范围
对构建内部 coding/web agent 的团队很实用：不动模型权重、把评估算力转化为持久 harness 能力的思路成本低、风险可控，preserve-and-extend 契约可直接借鉴用于防止自动迭代中的性能回退。
Evo-Bench: Can Language Models Improve Agent Harness?
arXiv:2608.09096
创新点
首个评测模型"自主进化自身 agent harness"能力的 benchmark，覆盖 Search、Office、General 三个 agent 域。核心方法是 harness-guided construction：用 auxiliary-task evolution 筛选出对框架改进真正敏感的任务，再做 sensitivity-aware stratified splitting 保证跨 suite 泛化，从而把 harness 改进能力从 base 模型实力中隔离出来。
结论
九个前沿与开源模型上，顶尖模型自主进化 harness 的绝对提升最高达 16.6 分，接近 SOTA 人工设计基线；自主进化在 General 任务上超越人工 harness、Search 任务表现优秀，但在需要高度特定处理流程的 Office 任务上吃力；进化出的 harness 是可迁移的推理结构，能稳定提升不同 policy 模型；同时发现 early saturation 等时间维度异常。
结论支撑
任务构造方法论（敏感性筛选 + 分层划分）针对 benchmark 污染与过拟合的设计较严谨，9 模型规模和 harness 跨 policy 模型迁移实验增加了结论可信度。16.6 分提升有明确数字。但 Office 域的负结果提示结论域依赖强，"接近人工基线"的基线质量会影响结论强度。
局限性
仅覆盖三个 agent 域，Office 上的失效说明适用范围有界；早期饱和现象暗示长 horizon 进化收益可能有限；harness 质量的评估依赖基准自身设计；未讨论进化过程的算力成本与样本效率。
点评与适用范围
对做 agent 框架（harness/scaffold）工程和 agent 评测的团队都有参考价值：一方面提供了自进化能力的标尺，另一方面"进化的 harness 可迁移到不同 policy 模型"说明 harness 工程有独立于模型的资产价值。直接落地意义一般，更适合作为研究评测工具。
Macaron-V1: Towards Open Continual Learning with Self-Improvement and Mixture-of-LoRA
arXiv:2608.09819
创新点
提出面向 experiential intelligence 的开放 agent 模型家族：用 Mixture-of-LoRA 冻结底座、组合专家 LoRA（每轮对话选一个）实现持续扩展；用 Model-Harness Co-design 和递归自我改进闭环（外部 contract 评估经验、构建下一代 versioned model-harness pair）替代传统的固定训练-部署流程。
结论
旗舰 Macaron-V1-Venti 基于 744B GLM-5.2 底座挂 4 个 LoRA（chat/agent/coding/GenUI），另有 50B 的 Qwen3.6-based Tall 版本支持本地部署。在 Personal Intelligence、GenUI 和通用能力基准上验证了当前系统，但持续学习与集体智能的复利增益仍是开放问题。
结论支撑
作为系统报告，覆盖架构、算法、基础设施三层：UI4A GenUI harness、有状态 action substrate、versioned HCP contract、agentic RL 框架 MindForge、后训练平台 MinT、长上下文 RL 方法 LongStraw 及稀疏 MoE/DSA 稳定性技术。评测对标前沿 baseline，但作者坦承持续学习增益未证实。
局限性
摘要明确承认 continual learning 和 collective intelligence 的复利增益仍是 open question；系统组件繁多，各模块的独立贡献难以剥离；依赖 744B 超大底座，复现和资源门槛高；未见 ARC 式长期部署实证。
点评与适用范围
适合做大模型 agent 系统、Model-Harness 协同设计和 agentic RL 基础设施的团队参考，尤其是 Mixture-of-LoRA 的持续学习组织方式。落地难度大：整套系统是重型工程，单一团队宜抽取 MoL 架构或 LongStraw 等子模块借鉴，不宜整体照搬。
MatrAIx: Simulating the World with 8.3 Billion Persona Agents

创新点
针对现有 agent 评测"短请求、静态环境"的盲区，提出面向日常生活的长 horizon benchmark：200 个任务横跨十个生活域，每个任务是仿真世界中跨数周的脚本化时间线，环境含 22 个 mock 服务，世界自行演进且多数变化是静默的——只有主动复查世界的 agent 才能发现变化。评测考察主动性（何时行动/询问/沉默）、持久性（计划首尾一致）与未明言的隐含约束。
结论
七个前沿模型全部得分很低，显示当前 agent 距离真实生活助理还很远。评分采用细粒度加权检查，只读取 agent 实际留下的痕迹，覆盖终态、行动时效性与隐含约束遵守三个维度。
结论支撑
评测设计有新意：静默变化的世界 + 只检查行为痕迹的评分方式，能有效区分"被动应答"与"主动持续"的 agent，这是多数 benchmark 测不出的维度。200 任务/10 域/22 服务的规模可观。摘要未给出各模型具体分数，"全部低分"的幅度未知；脚本化世界的多样性边界也是潜在问题。
局限性
脚本化时间线的仿真世界与真实生活复杂度仍有差距；22 个 mock 服务的覆盖有限；摘要无具体分数，无法判断各模型差异量级；评分依赖预设检查点，对未预料的合理解法可能误判；尚未见开源后的社区验证。
点评与适用范围
适合个人助理类 agent 产品和 agent 评测团队关注，"主动性与持久性"是下一代生活 agent 的核心差异点，该 benchmark 的静默变化机制设计值得借鉴。任务、环境、评测框架承诺开源，接入成本低，可作为 agent 产品的回归测试集。

重点精读On-Policy Self-Distillation without Any Supervision
arXiv:2608.06296
创新点
提出 U-OPSD：完全抛弃 ground-truth、环境反馈和大模型指导，仅用模型自身采样实现 on-policy self-distillation。方法先多次 rollout 并在自洽阈值下多数投票构造 pseudo-solution，再以该伪解为条件蒸馏那些与之分歧的 completion，让模型精准纠正'自信地错'的位置，实现真正意义的自蒸馏。
结论
在 AIME24/25、HMMT25、MATH500、AMC23 五个数学基准上，Qwen3 non-thinking 模式 4B/8B 分别较基座提升 8.5%/10.7%，平均超出有监督 OPSD 3.2%/2.3%；thinking 模式与 OPSD 持平（4B 领先 0.9%、8B 持平），并分别超 GRPO 0.7%/1.1%。
结论支撑
跨多基准、多基座、non-thinking/thinking 两种模式及 4B/8B 规模的系统对比，对手包括带 GT 的 OPSD 和 GRPO，设置合理且有说服力。局限在于多数投票伪解的质量依赖模型已有能力——对基座几乎不会的任务，多数票可能系统性错误，摘要未讨论此类失败边界。
局限性
方法有效性上限受 self-consistency 约束：当多数投票本身错误时蒸馏会强化错误；评测集中在数学推理，代码、长文本、多模态等场景未验证；仅 4B/8B 规模，更大模型上自洽信号是否仍充足未知。
点评与适用范围
对后训练团队价值直接：无需标注、无需 reward model，工程上只是在现有 on-policy 蒸馏框架里换信号源，落地难度低。尤其适合缺少高质量 GT 的领域（数学之外的开放任务）做能力抬升，但要警惕伪解系统性偏差场景。
🔴 重点推荐理由
无监督 on-policy 自蒸馏在五个数学基准上反超带 GT 的 OPSD 和 GRPO，把后训练对外部监督的依赖彻底拿掉，工程改动小、收益直接。
重点精读Stealing Reasoning Traces from Proprietary LLM APIs

创新点

结论支撑
证据链扎实：在三家头部厂商真实 API 上验证跨模型注入解码；大规模实证（315,320 个公开泄露的块）量化 PII/credential 泄露规模；四类攻击向量逐一演示，并给出可操作的 mitigation，论证充分且经负责任披露流程。
局限性
攻击前提是会话日志或加密块被公开暴露，依赖开发者误分享；缓解方案的实际部署效果未评估；未覆盖所有厂商与所有模型组合，弱模型防护强度会影响攻击成功率。
点评与适用范围
所有使用带加密 CoT 的商业 API 做 agent 的团队都应读：会话日志不要公开分享。对做模型安全、红队、API 架构的团队是高价值参考；对训练侧团队则提示 anti-distillation 的现有防线可能被绕过，蒸馏防护需重新评估。
🔴 重点推荐理由
揭示主流厂商加密 CoT 的架构级漏洞，可直接绕过 anti-distillation 并大规模泄露 PII 与凭证，对 API 安全与模型防护体系影响重大。
DCAS: Decoupling CLI Agent Scaffolding to Internalize Planning across Scaffolds
arXiv:2608.06113
创新点
指出 CLI agent 生态的隐性陷阱：开源轨迹数据几乎都在 OpenHands 下采集，微调后的模型换 scaffold 即显著退化，而 base 模型无此问题——退化是微调引入的。作者区分 explicit planning（一等计划产物）与 implicit planning（agent loop 的结构惯例），并提出 DCAS：backend 替换拦截层，不改 scaffold 即可在任意 CLI scaffold 与任意后端模型间路由流量，支持跨 scaffold 评测与 planning-aware 轨迹采集。

论证链条设计巧妙：先用 base 模型无退化现象定位问题在微调而非能力，再用 plan-source 干预做因果验证，最后用少量轨迹微调验证可迁移性，层层递进。不足是摘要未给出具体 benchmark 分数与模型规模，"small set"轨迹的具体量级不明。
局限性
聚焦 CLI/软件工程 agent，结论对其他 agent 形态的适用性未验证；未说明所用 base 模型、评测 benchmark 与具体分数；planning-aware 轨迹的采集成本与规模效应未量化；explicit/implicit planning 的分离是经验性的，机理解释有限。
点评与适用范围
对做 agent 后训练（SFT 轨迹数据）的团队有直接警示价值：训练 scaffold 的惯例会被模型内化，数据配方里应显式处理 planning 结构。DCAS 拦截层本身也是实用的评测工具。借鉴难度低，核心是数据采集策略的调整。
Small Foundation Models of Human Cognition and Behaviour
arXiv:2608.05224
创新点
系统研究行为数据微调出的“认知代理”模型所需规模及其信息利用方式：在 Psych-101（160 个实验、1,070 万条 trial 级选择数据）上训练 135M–14B 的 14 个模型、覆盖 4 个架构家族。区分了分布内与分布外的 scaling 行为，并通过遮蔽 4 类 prompt 通道（任务指令、实验刺激、结果反馈、选择历史）和 trial 顺序置换两项诊断，定位模型真正使用的信息。

结论支撑
14 个模型×4 个架构家族的规模扫描加上 27 个实验的通道遮蔽与置换诊断，设计系统、数字具体（75.7% 信息摧毁、0.6B–1B 匹配 70B）。置换实验区分独立 trial 与响应依赖任务，分析细腻。整体方法学严谨，是行为微调方向少见的 scaling 实证。
局限性

UniSwap: Streaming Audio-Visual Identity Swapping for Talking Videos
arXiv:2608.11752
创新点
首个 talking video 中流式联合音视身份替换框架：用单一 audio-visual diffusion transformer 同时迁移参考外观与音色，替代以往两个模态独立优化的做法，从机制上保证音视一致性。针对跨身份配对数据稀缺提出 swap-and-reconstruct 自监督管线；训练分三阶段（In-context Pretraining、Conditional Streaming Adaptation、Efficient Self-forcing DMD），采样从 30 步降到 3 步，三个 DMD 角色经 Multi-LoRA Switching 共享冻结骨干。
结论
实验显示强音视同步性、有竞争力的身份保持、高效流式生成和稳定的长视频生成；Efficient Self-forcing DMD 缓解 exposure bias 并将每 block 去噪步数从 30 减到 3；Feature-RoPE Decomposition 让缓存位置保持在训练范围内，支撑长序列稳定推理。
