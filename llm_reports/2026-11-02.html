Continual Learning Exam: Benchmarking Long-Horizon RSI and Experiential Learning in LLM Agents
📅 2026-10-25 Agent评测持续学习Benchmark经验驱动改进 arXiv:2610.33956 HF 👍 45
创新点
提出 Continual Learning Exam（CLE）benchmark，把评估目标从'单任务表现'转向'从积累的经验中持续改进'：由 50+ 领域专家构建 120 个人工撰写任务，每个任务为五级阶梯共 600 级，覆盖 89 个职业角色、12 个行业领域；必须逐关解锁，后续关卡建立在前面作业积累的经验上。评测设置含单次提交与'失败后给诊断反馈并可修改一次'两种模式，用评估 agent 按人工 rubric 打分。
结论
17 组 harness-model 配置（均为前沿 LLM）下，反馈+修改仅带来 5.3 个百分点的中位完成率提升；最好的系统也只通过 47.7% 的关卡，仅 23.3% 的任务能完成全部五级。结论：当前前沿 LLM 的持续经验学习能力仍然薄弱，长程改进远未解决。
结论支撑
大规模人工任务（600 级）+ rubric 化评估，双设置（单次 vs 反馈修改）对照合理，且任务需逐关解锁，较真实地模拟经验依赖。评估 agent 按 rubric 打分可能引入评判偏差，人工 rubric 质量是潜在变量。
局限性
职业工作流与真实职场复杂度仍有差距；结果仅覆盖所测的少数前沿模型；评估 agent 的可靠性未做充分的人评校准；难度可能随领域专家的主观经验偏移。
点评与适用范围
适合 agent 评测与后训练团队：CLE 既是指向持续学习瓶颈的标尺，也可直接用作 post-train 数据（作者明确建议）。对评估长程 agent 记忆/学习机制的研究有较高参考价值，落地难度低（直接使用）。
How Far Can Coding Agents Go in Visual Generation?
📅 2026-10-13 Coding Agent视觉生成视觉推理能力分析视觉思维语言 arXiv:2610.19025 HF 👍 31
创新点
系统研究通用 coding agent 通过可执行程序'画'图像的能力边界，提出 200-prompt 的 AgentDrawBench；并提出两个概念：代码作为'外部视觉思维语言'（结构化、可执行、可检查的视觉表示）和'内部视觉思维语言'假设（跨绘图语言共享的组合化场景表征）。后者通过跨 harness 绘图、独立单像素查询组装的图像、以及移除可见绘图后跨视角保持房间布局等实验进行探索。
结论
Coding agent 的能力画像鲜明：在结构保持和精确视觉约束上表现出色，在组合准确性重于照片级真实感的领域有竞争力，但感知丰富度不足。重构出的视觉代码在 VQA 中保留大量信息，某些领域甚至比原始图像准确率更高；跨 harness 绘图呈现一致的布局与色调，支持 agent 在生成前就维持连贯内部世界的假设。
结论支撑
200-prompt benchmark + VQA 定量实验 + 多组定性/一致性实验（跨 harness、单像素查询、视角变换），实验组合有想象力。但多数关键结论（内部表征一致性）依赖定性观察，缺少严格的统计检验；benchmark 规模偏小。
局限性
AgentDrawBench 仅 200 prompt，统计效力有限；感知丰富度的瓶颈未定量分析；'内部视觉思维语言'是间接推断，缺乏对模型内部的直接证据；评测 agent 未指明具体型号。
点评与适用范围
偏认知与分析型研究，适合关注 agent 能力边界、多模态表征的团队；对实际图像生成工作流（扩散模型已很强的领域）的直接工程价值有限，但'代码作为可检查视觉表示'对可解释视觉推理有启发。
RSIHub: A Composable Framework for Agent-Evolution Methods
📅 2026-10-23 智能体演化框架Agent评测开源基础设施 arXiv:2610.32253 HF 👍 49
创新点
把 agent-evolution 方法反复重造的实验机器抽象为共享基础设施：框架提供执行、评测、恢复与血缘追踪，方法以 recipe 形式组合可复用 operator 并声明可变资源，且评测置于可变面之外、结果与候选及评测条件绑定。在框架核心不改的前提下实例化 AHE、Hyperagents、A-Evolve、GEPA 四种代表性方法。
结论
在 Terminal Bench 2 与 τ³ Banking 上（MiniSWE 与 Codex 两种 executor、固定模型与评测配置），观测到的最大整体 pass@1 提升为 13.5 个百分点；但方法排名随设置变化，优化收益不一定迁移到 held-out 任务——诚实暴露了 agent 演化方法的不稳定性。
结论支撑
固定模型与评测器的多方法横向对比，并考察排名稳定性与迁移性，框架类工作中实验设计较规范；但仅覆盖 2 个基准与 2 种 executor，结论外推性有限。
局限性
只实例化 4 种方法与 2 个 benchmark；agent-evolution 收益对任务和模型高度敏感，框架本身不保证任一方法有效；长期大规模演化的稳定性与成本未深入分析。
点评与适用范围
适合研究 agent 自我演化/自动改进的团队作为实验底座，避免重复造轮子；其"评测不变面 + 候选血缘追踪"的设计对工业界 Agent 优化平台也有借鉴价值；落地门槛低。
HABIT-Bench: Evaluating Habit Induction from Longitudinal Weak Evidence in Agent Memory
📅 2026-10-20 Agent记忆个性化Benchmark习惯推理 arXiv:2610.24520 HF 👍 39
创新点
首个针对 agent memory 的"习惯归纳"专项评测：从任务型对话数据与受控 habit graph 合成跨数百 session 的用户历史，四选一任务考察习惯归纳与适时应用，特别包含临时例外、习惯改变、用户未接受的建议等真实干扰情形，抽样任务经独立人工审核。
结论
8 种记忆方法在 Qwen3-235B-A22B 与 GLM-5.3-Flash 上评测，最佳方法在四领域 macro accuracy 仅 33.61%；即使直接把标注证据供给模型性能仍然有限，揭示了"能访问历史"与"能归纳并恰当使用习惯"之间的持续鸿沟。
结论支撑
覆盖餐饮、金融、软件、出行 4 个领域、数百 session 的合成历史，加独立人工审核与双模型评测，对"当前记忆方法不足"这一结论证据充分；局限是历史为合成、任务形式为四选一的简化设定。
局限性
用户历史系合成生成，真实长期用户行为的噪声与多样性未覆盖；四选一形式简化了真实场景的开放式生成需求；只测两个模型；受控 habit graph 的分布可能不覆盖真实习惯的复杂度。
点评与适用范围
做个性化 agent、长期记忆系统的团队应将此基准纳入评测；当前数字说明该方向远未解决，有明确研究空间；评测数据与协议落地门槛低。
InteractiveWorld: A Verifiable Human-Centric Environment for Building Better Interactive MLLM Assistants
📅 2026-10-25 Agent评测MLLM具身智能Benchmark arXiv:2610.33966 HF 👍 56
创新点
首个可验证的人机闭环交互环境：与机器人中心模拟器不同，由 AI 助手指导一个会自主观察场景、理解指令并独立行动的人类 agent，环境执行动作并更新双方观测，真实模拟助手指导人干活的协作模式。基于此构建 InteractiveBench：120 个多轮任务覆盖 6 大类，每步指令都影响结局，用可验证的状态奖励打分而非 judge 打分。
结论
12 个前沿 MLLM 距离可靠的第一人称助手还很远：最强模型 Claude Fable 5.1 在长程 Guidance 任务上最多 20%、Planning 任务最多 25%，揭示多轮物理指导是当前模型的明显短板。
结论支撑
120 任务 × 12 模型的系统评测，状态奖励可验证、避免了 LLM-as-judge 的偏差；按任务类别分解暴露长程任务的瓶颈。局限在于人类 agent 是模拟的，真实人类的理解偏差与执行不确定性未覆盖。
局限性
120 个任务规模相对有限；模拟人类 agent 的行为模型可能引入系统性偏差；环境覆盖的物理场景与物体类型有限，结论外推需谨慎。
点评与适用范围
对做可穿戴/具身 AI 助手、agent 闭环评测的团队有直接参考价值，状态奖励的可验证设计值得借鉴；也适合作为 agent 能力摸底工具。落地难度低（纯评测环境）。
The Trinity: Capability-Driven Recursive Self-Improvement for Multimodal Agents
🔴 重点精读 📅 2026-10-26 多模态Agent自我改进环境生成Real2Sim2Real arXiv:2610.36077 HF 👍 44
创新点
提出能力驱动的多模态 agent 递归自我改进框架 The Trinity，以 Creator/Explorer/Evolver 三角角色耦合世界生成与 Harness 进化：Evolver 基于验证执行轨迹把按表面类别组织的任务树重组为层次化能力树；能力驱动 Real2Sim2Real 为同节点异构任务抽象出简化可验证的模拟世界用于能力学习、回原任务测迁移；Explorer 沿能力树选择性继承进化可复用能力模块形成 Harness 树，并配能力感知路由器按公开任务信息选择模块配置。核心洞察是不同模态/表面形式的任务可共享底层能力需求。
结论
进化得到的 Harness 在 28 个训练基准上平均提升 34 分，在 18 个未见基准上平均提升 26 分（含两个真实具身任务），表明按能力组织训练与复用模块比按表面任务类别组织更能泛化。
结论支撑
训练基准与未见基准分离评估，未见基准上的 26 分提升是泛化性的关键证据，并包含真实具身任务验证 Sim2Real 迁移；递归迭代中验证后的模块更新在固定拓扑内累积。摘要未披露具体基准名称、底座模型与方差， claim 强度待全文确认。
局限性
框架复杂，多角色递归循环的工程与算力成本高；能力树的构造质量依赖 Evolver 的判断，可能引入组织偏差；未见基准虽与训练分离，仍可能存在任务分布相似性导致的高估。
点评与适用范围
对做多模态 agent 自动课程生成、环境生成、agent 后训练的团队有较高启发价值，能力树+模块化 Harness 的范式与工业界 agent 训练平台的方向契合；落地需较强工程能力，建议研究型团队先在小规模任务闭环试点。
推荐理由
能力树驱动的 agent 递归自我改进框架，未见基准平均 +26 分且迁移到真实具身任务，为多模态 agent 自动进化提供了少见的完整可落地范式。
Work Agents: Systems, Capabilities, and Optimization
📅 2026-10-26 Agent综述框架运行时HarnessAgent评测 arXiv:2610.35845 HF 👍 116
创新点
提出以"工作（work）"为中心的 system-level 视角，将 work agent 定义为 foundation model 与 runtime harness 结合、在有状态工作空间中交付可验证结果的系统。引入 work persistence 与 work openness 两个互补维度刻画工作条件，并按任务范围与组织方式将数字工作分为五种形态，归纳出支撑可靠工作执行的五大能力族。进一步系统梳理 model optimization、harness optimization 及二者联合优化三条技术路线，并从工作结果视角重审评测方法。
结论
作者核心论点：agent 交付可靠工作的能力不仅取决于模型本身，更取决于 harness（运行时支撑结构）与工作条件的匹配；任务通过率等表层指标不足以衡量工作质量，评测应转向可验证的工作结果（work outcomes）。论文还指出持续工作委派、开放环境适应、工作执行与能力改进的交互是未来关键方向。
结论支撑
本文是 framework/综述型论文，无新实验；论证基于对现有文献的分类、组织与概念抽象，两位作者所在团队（BUPT/MSRA 等）在 agent 方向有多篇前期工作。框架提供了统一的术语体系（维度、五类工作、五大能力族、三类优化），便于后续研究对号入座。
局限性
框架有效性未经大规模定量验证，维度与能力族的划分边界较主观；三类优化路径的实际收益缺乏对比数据；五种工作形态的区分标准在现实混合任务中可能模糊。
点评与适用范围
适合 agent 平台/框架团队（Coding Agent、办公自动化 agent 等）作为概念地图和 checklist 使用，尤其 harness 工程（上下文管理、工具编排、治理与验证）部分有参考价值。落地难度低（概念层面借鉴），但对具体算法改进的直接指导有限。
Trial by Trace: Benchmarking AI Agent Harnesses for Reliability and Failure Attribution
📅 2026-10-23 Agent评测Harness可靠性失败归因Benchmark arXiv:2610.32285 HF 👍 53
创新点
现有 benchmark 多聚焦模型能力与 agent 整体表现，本文首个系统评测 agent harness（运行时支撑结构）本身：将 harness 可靠性拆为 context、execution、governance、lifecycle、observability、tools、verification 七大组件；构建 95 个专家级机制导向任务，配可执行或状态化 ground truth，在保留各 harness 原生行为的前提下支持语义等价比较。技术上设计 Trajectory Tracing 轨迹采集、双层评估框架（agent 表现与 harness 可靠性分开评）、Multi-source Evidence Acquisition 多源证据采集，以及基于显式机制链的运行级 Failure Attribution 模块。
结论
对 4 个 harness、9 个模型、95 个任务共 3,420 次运行的评测显示：harness 宏观得分仅 59.8%-72.0%，可靠性普遍不足；更值得注意的是 31.1% 的运行任务成功但至少违反一项 harness 准则——任务成功不等于 harness 可靠，仅靠成功率会掩盖系统性风险。
结论支撑
3,420 runs 的大规模实验 + LLM-based 评估结合多源证据（agent 上下文、harness、执行环境）交叉验证；机制链归因把失败定位到具体 harness 组件，诊断粒度细。任务设计为机制导向且 ground truth 可执行，比较口径较严谨。
局限性
仅覆盖 4 个 harness、9 个模型，多样性有限，结论的跨 harness 泛化性待验；95 个专家任务偏机制检验，与真实复杂工作场景的差距未量化；LLM 评判器引入的偏差未充分消融。
点评与适用范围
适合 agent 平台工程团队（Coding Agent、办公 agent 基础设施组）借鉴其七组件检查清单、轨迹追踪与失败归因方法，用于 harness 选型与回归测试。落地难度中等，价值主要在于方法论而非直接可用工具。
Principia: Test-Time Hypotheses to Principle Construction for Scientific Discovery
📅 2026-10-23 科学发现LLM框架test-time学习假设归纳 arXiv:2610.32195 HF 👍 42
创新点
提出 test-time 构建并持续精炼科学原理的 LLM 框架 Principia：从相关输入及其观测结果构造对比因果假设，再跨假设归纳反复出现的关系形成归纳原理；将假设与原理应用回任务获得新观测，据此修正假设、重构原理，使科学知识在推理过程中持续进化。这把传统上需要大量领域专家完成的'假设→原理'翻译环节自动化，消除科学发现流水线瓶颈。
结论
在分子优化、蛋白质工程、基因扰动、分子性质预测四类科学发现基准上，Principia 优于依赖内部知识、外部来源或经验总结的基线；生成的原理合理且与科学文献一致，证明 test-time 原理构建对任务特定科学发现有效。
结论支撑
四类 AI4Science 基准横向评测 + 生成原理的文献一致性评估，覆盖不同发现子任务，任务多样性较好；与三类基线（内部知识/外部检索/经验总结）对比验证了原理构建的价值。但各基准规模、迭代轮数与成本细节披露有限。
局限性
