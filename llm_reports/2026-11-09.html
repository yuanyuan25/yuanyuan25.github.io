Advances in Agentic Computer Graphics
📅 2026-11-01 arXiv:2611.01860 HF 👍 144
创新点
针对 agentic computer graphics 领域术语不一、发展过快难以人工跟踪的问题，提出统一的分类体系（taxonomy）刻画各类图形任务中 LLM agent 系统的共性，并构建了可规模化分析新发表论文的 agentic 文献系统。这是该方向首个系统性梳理报告，把分散的图形 agent 工作纳入同一框架。
结论
作者梳理出 agentic 图形学的研究趋势，并指出四大开放挑战：跨图形任务的 agent 与工具协调、人机协作的界面与表示设计、长程规划与持续 refinement、交互式图形系统的可靠评估。核心论点是图形算法将越来越围绕 agentic 系统构建以自动化复杂任务。
结论支撑
基于对大量已有文献的系统分类与趋势分析（报告达 10.4MB），并用自建 agentic 文献系统演示规模化分析能力。属于综述性论证而非实验验证，覆盖面和分类一致性是其主要支撑。
局限性
结论依赖公开文献采样，可能遗漏非公开或最新工作；文献系统的准确率与覆盖度缺乏严格定量评估；开放挑战多为定性讨论，未给出可操作的 benchmark 或验证方案。
点评与适用范围
适合图形学与 Agent 交叉方向的团队作为入门地图和术语对照表，也可供做 agent 综述文献系统的团队借鉴方法论；对纯 NLP/Agent 团队参考价值有限。阅读门槛低，但复现其文献系统需较大工程投入。
From Autonomous Agents to Cognitive Symbionts: Toward AI-Augmented Human Intelligence
📅 2026-11-03 arXiv:2611.05376 HF 👍 118
创新点
提出 AI-augmented human intelligence (AHI) 范式与"cognitive symbiont"（认知共生体）概念：终身的、嵌入式、实时、私密、低摩擦、主动的陪伴系统，通过外部设备感知人所感，跨多年保持上下文并建模情境与心智。以 cognitive gap（人可为情境调用的能力 vs 工作记忆能承载的）为概念核心，组织为感知-保持-理解-陪伴-代行与共思-成长的 symbiosis loop，并将治理内置于范式本身。
结论
作者主张 Physical AI 时代应包含两类智能个体：具身机器人与 AI 增强的人；与 AGI 追问"机器能多智能"并行，AHI 追问"机器能为某个具体的人赋能多少智能"。symbiont 会改变人在他人面前的能力表现，带来新型风险（如隐蔽辅助、全员被迫采用的社会压力），治理是范式不可分割的一部分。
结论支撑
纯概念/立场性论证（59 页、21 图、18 表），通过构建设计空间、symbiosis loop 框架与风险分类展开，无实验或系统实现支撑，属于愿景式 whitepaper。
局限性
无技术实现与实证评估，概念可操作性未经验证；隐私、安全与治理讨论停留在框架层面；终身感知个人数据涉及的法律伦理障碍未给出可行解。
点评与适用范围
适合做个人智能体、可穿戴 AI、人机交互产品的团队用来梳理愿景与风险清单；对追求可落地算法的团队参考价值有限。作为思想框架易读性好，但距离系统落地差距大。
CoworkOS:Scaling Agent Coworkers for Real-world Automation
📅 2026-11-02 后训练 arXiv:2611.03178 HF 👍 100
创新点
提出通用长程 cowork agent harness，将任务策略（模型决定动作、委派与验收）与执行管理（运行时维护状态与反馈）分离；三层架构支持直接执行或同步/异步委派 Subagent 且职责稳定。核心是共享应用层：人与 agent 检查/修改同一份演进中的文档、PPT、CAD 模型与 Blender 场景，人机协作既可经对话进入也可直接修改工件本身；配合分层 workspace 与持久语义记忆，使文件、关键决策与长 Job 日志可共享、复用、断点续跑。
结论
在 12 个 benchmark 与 6 类真实应用上，CoworkOS 与 Codex、DeepSeek Harness 等前沿 agent 应用高度竞争；持续工作案例中以 GLM-5.3 为骨干对 Qwen3.6-35B-A3B 做 RSI 驱动的自动化后训练，五轮后 8 个 benchmark 均分从 33.19 升至 42.95（+9.76）；作者认为该路径可通向通用 cowork-agent 智能。
结论支撑
覆盖 12 个 benchmark 与 6 类真实应用的广泛评测并与前沿系统对标，持续工作案例给出五轮自动化后训练的量化提升。局限在于对比的模型、算力与轮次条件未必完全对齐，benchmark 细节与可复现性披露有限，且 +9.76 的绝对分数水平仍不高。
局限性
与 Codex/DeepSeek Harness 的对比条件未必公平（各自模型与算力不同）；自动化后训练仅跑 5 轮、绝对分数仍低，长期收敛性与自我改进上限未知；harness 工程复杂，外部团队复现成本高。
点评与适用范围
适合构建 agent 产品或内部自动化平台的团队参考其策略-执行分离、共享工件层与持久记忆的设计；RSI 式自动化后训练闭环对训练团队有启发，但需先评估投入产出比。整体落地难度中高，需要完整运行时与应用层生态配套。
Harness-S: Learning from Sibling Harnesses for Generalizable Agent Training
📅 2026-11-03 RL 后训练 工具调用 SWE Agent arXiv:2611.04277 HF 👍 66
创新点
把 agent 的 harness（执行脚手架）从'寻找一个万能 harness'的思路转变为训练时资源：沿不同修复方向演化出专门的兄弟 harness 池，仅当 base harness 下所有尝试失败时才调用辅助 harness 重新 rollout，用成功轨迹替换失败组做 RL，将 harness 激发出的行为迁移回单一 policy。配套基于行为画像+多 LLM 投票的自适应路由器（Adaptive Harness Router）和随 policy 进化刷新的 policy-aware 画像再锚定。与以往直接换 harness 或直接用 harness 推理的工作不同，重点是能力回灌而非依赖脚手架。
结论
在 AppWorld、SWE-Gym、DBBench 上，训出的 policy 回到原始 base harness 后显著优于纯 policy 训练；行为分析和 held-out 案例支持 harness 诱发行为确实被内化进 policy 本身；复用路由器做 Rank-1 推理在同 rollout 预算下还有额外收益。
结论支撑
覆盖 SWE、App 自动化、数据库三类 agent 基准，设 policy-only 训练对照，并辅以行为分析和 held-out 案例交叉验证，实验设计较完整；但基准仅 3 个，未验证跨基座模型和更大规模场景的泛化。
局限性
需预先构建和演化 harness 池，工程成本不低；路由器依赖多 LLM 投票，引入额外推理开销；harness 池训练期内固定，policy 快速进化时互补性可能漂移（虽有 re-anchoring 缓解）。
点评与适用范围
适合正在做 coding agent / 工具调用 agent RL 训练的团队，尤其对 GRPO 类训练中失败 rollout 大量浪费算力的场景有直接借鉴价值。落地需要一定的 harness 工程投入，难度中等。
Does Scaling Toward AGI Depend on What System-1 Lets System-2 Execute?
📅 2026-10-29 理论分析 推理效率 Test-time Compute Scaling arXiv:2610.39497 HF 👍 64
创新点
提出'条件交互'（conditional interaction）框架——predict-gate-execute-update 循环：轻量 System-1 预估每个候选交互的效用，System-2 只执行通过自适应阈值的交互，执行结果再更新 System-1。理论上证明理想筛选下执行算力可降至约 1/ρ_u（ρ_u 为效用相关交互密度，成本不等时按成本加权），并用预测器误差和效用 margin 界定选择遗憾。核心假说是 ρ_u 是 scaling 效率的可测坐标，'informative compute'比总算力更能刻画扩展。与以往单纯堆大 System-2（更大模型、更长推理、更多 agent）的路线不同，主张 System-1/2 协同设计。
结论
作者给出限定性肯定回答：与 System-1 协同设计确实能显著降低 AGI 扩展的执行成本，节省上界由效用相关交互密度 ρ_u 决定；informative compute 是比 total compute 更好的 scaling 描述坐标。
结论支撑
以理论推导为主：给出算力节省因子、选择遗憾上界等界，并将循环泛化到训练、测试时推理、自适应决策、agent 工具使用四类场景。缺乏大规模实证，验证强度弱于典型方法论文。
局限性
结论建立在理想筛选、效用与成本可定义等假设上；System-1 预测器自身的训练成本及误差-收益权衡缺乏实证；ρ_u 的可测量性与跨任务一致性未充分验证。
点评与适用范围
适合研究 test-time compute 分配、agent 推理预算控制的理论与算法团队，提供'算力该花在哪些交互上'的分析视角和新的效率坐标。偏研究纲领性质，短期工程落地价值有限。
FrontierPhysics: Evaluating Agents for End-to-End Physics Research
📅 2026-11-04 arXiv:2611.06910 HF 👍 59
创新点
首个端到端的物理研究智能体基准：56个任务由42位物理学家基于自己的真实研究设计，覆盖理论/计算/实验9大领域，要求智能体完成文献调研、研究规划、实验执行、结构化输出到论文撰写的完整研究流程。与固定问答式物理基准或给定解的论文复现基准不同，它结合确定性验证器与专家评分量规，同时评估研究正确性与"可发表性"。
结论
22个模型26种配置中，无一能通过超过46/168次rollout。人工轨迹审查表明，前沿智能体的主要瓶颈是推理不够严谨和缺乏专家直觉，而非物理知识缺口或执行错误。
结论支撑
由42位物理学家产出真实研究任务，每个配置168次rollout，评估采用确定性验证+专家量规双通道，并辅以专家人工轨迹审查，实验设计较全面；但可发表性评估依赖量规，存在主观评分方差。
局限性
56个任务相对真实物理研究多样性仍有限；"可发表性"判据依赖专家量规，主观性难完全消除；结论对物理之外的其他科研领域的泛化性未验证。
点评与适用范围
适合AI4Science方向及构建科研自动化管线的团队，用于评估research/coding agent的真实研究能力；基准可直接使用，落地门槛低，但复现其中实验物理任务的环境成本较高。
Axion 1.0: Open Agent Foundation Models, Simplified
🔴 重点精读 📅 2026-11-02 RL 后训练 arXiv:2611.03233 HF 👍 49
创新点
提出极简三阶段训练配方：第一阶段用模型感知数据构造（依据基座模型自身成功解题策略合成难题并对抗式增强）建立自包含推理；第二阶段通过 grounded 于真实数据源与确定性计算的可扩展管线构建多样化、自动可验证的工具任务，扩展出工具依赖推理；第三阶段 RL 强化长程推理与环境交互。全程无专门 mid-training、DPO 或 OPD。相比以往 agent 模型堆叠多阶段复杂配方，证明了'开放且简单'的可行路径。
结论
紧凑配方下 Axion 1.0 在广泛 agentic 基准套件上取得强劲性能，在若干基准上与领先商业模型有竞争力；说明强 agent 能力不依赖复杂的训练阶段堆叠，三阶段（推理 SFT → 工具 SFT → RL）即可。
结论支撑
在一系列 agentic benchmark 上与商业模型及基线对比，并通过阶段消融验证各阶段贡献；训练任务均自动可验证，评测信号可靠。实验设计合理，但摘要未披露具体分数与模型规模细节。
局限性
摘要层面未给出各基准具体得分，与最顶尖商业模型在最难长程任务上的差距不明；RL 阶段的规模、奖励设计等细节需读正文。
点评与适用范围
适合希望复现或改进开放 agent 模型的团队，完整配方（数据构造/过滤/验证/训练代码）可直接借鉴作为 agent SFT+RL 基线；落地难度中等，需具备可验证任务构造与 RL 训练基础设施。🔴 重点精读理由：完全开放的 Agent 基座模型：仅三阶段极简配方（两阶段 SFT + RL）即在多个 agentic 基准上对标领先商业模型，且完整开源数据构造、验证、prompt 与训练代码，可完整复现。
R^2Orch: Recursive Self-Improvement for Agent Orchestration via Self-Play within a Skill-Internalization Loop
📅 2026-10-22 RL arXiv:2610.22740 HF 👍 48
创新点
提出递归自博弈编排（Recursive Self-Play Orchestration）新范式：内循环通过自博弈在自选题上改进 orchestrator，外循环改进'内循环如何改进'。配套两个核心机制——Recursive Learnability（奖励 Proposer 选择随技能撤回仍产生不同 rollout 结局的任务，天然缓解优势坍塌）和 Skill Withdrawal（受控评估显示不用某技能表现不降时将其撤回）。失败被蒸馏成技能、技能内化为参数、撤回又引导 Proposer 发现新失败，形成闭环，最终走向 zero-skill 部署。与以往手工设计课程或单次噪声评分评估技能的做法根本不同。
结论
R^2Orch 解决了编排学习三大痛点：手工课程设计、rollout 同结局导致优势坍塌、单评分信号不可靠；在 12 个数据集上（QA、数学、代码、交互任务）稳定超越基线。
结论支撑
12 个跨四类任务的数据集对比实验，含消融验证 Recursive Learnability 与 Skill Withdrawal 的贡献，代码开源；自选题与自评估设计较严谨。
局限性
任务与技能均来自自我生成，存在自我强化偏差风险；评测以标准学术基准为主，在真实生产级复杂任务上的泛化性未验证；双层递归训练成本与稳定性细节披露有限。
点评与适用范围
适用于多工具/多技能编排场景（如 multi-agent workflow、工具调度系统）的团队借鉴其自我课程与技能内化思路；范式抽象度较高，实现双层循环与受控评估的落地难度中高。
CUA-Master: Scaling Computer-use Agents through Open-World Recursive Improvements
🔴 重点精读 📅 2026-11-02 预训练 arXiv:2611.03126 HF 👍 48
创新点
提出嵌套双循环递归改进框架：系统层外飞轮（world-data-model）持续吸收开放世界语料，并利用模型演化的弱点指导下轮数据构造与优化；数据层内飞轮耦合'开放世界播种'（从教学视频挖掘真实工作流作种子任务，视觉-语义双路轨迹重建）与'自催化传播'（将种子转为可复用原语，可控合成多样化复杂可验证任务）。另提出反馈引导的快照-回滚重试机制，保障真实环境中轨迹采集的高效可靠。与以往依赖自生成经验、收益递减的递归改进不同，开放世界种子使能力持续扩展。
结论
CUA-Master-27B 在 GUI-only 与 GUI-CLI 混合基准上达强竞争力：OSWorld Verified 80.2、OSWorld 2.0 36.9、WeaveBench 43.9、Agents' Last Exam 25.0；框架显著提升数据合成的质量与效率，并随递归迭代持续增益。
结论支撑
