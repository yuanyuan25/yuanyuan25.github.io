🔴 JoyAI-VL-Interaction: Real-Time Vision-Language Interaction Intelligence

arXiv: 2606.14777 | 👍 211 | Dingyu Yao, Junhao Zhou, Chenxu Yang, Chuanyu Qin, Haowen Hou | HF
创新点：将视觉语言模型从被动问答改造成持续感知的主动交互 Agent：模型按秒自主选择静默、响应或委派后台模型，并提供包含流式视频、ASR、TTS、记忆和外部 Agent 接口的完整开源系统。
结论：具备自主响应决策和时间感知能力的视觉交互模型，可以在真实连续场景中提供比传统轮次式视频助手更自然、更及时的交互。
结论支撑：在六类真实场景的人类偏好评测中，JoyAI-VL-Interaction 相比 Doubao 和 Gemini 的应用内视频助手获得明显更高的偏好；论文还展示了跨动态界面引导和基于幻灯片即兴讲解等未显式训练能力。
局限性：摘要未披露评测样本规模、延迟、误触发率和漏响应率；持续视频处理带来的算力及隐私成本也未量化。与商业系统的比较可能受到系统配置和接口差异影响。
点评与适用范围：适用于实时视频助手、安防监控、直播、电商导购和屏幕操作指导。其核心价值是主动交互范式与完整工程闭环，而非单纯提升静态 VQA 精度。
重点理由：首次将开放的视觉驱动主动交互模型、训练方案、数据和可部署系统完整结合，为 always-on 多模态 Agent 提供了可复现基线。

MemSlides: A Hierarchical Memory Driven Agent Framework for Personalized Slide Generation with Multi-turn Local Revision

arXiv: 2606.17162 | 👍 176 | Ye Jin, Yangyang Xu, Jun Zhu, Yibo Yang | HF
创新点：提出面向演示文稿 Agent 的分层记忆架构，将长期记忆细分为用户画像记忆和工具记忆，并以工作记忆承载会话约束；同时采用最小影响范围的 slide-local revision，避免局部修改时重复生成整套幻灯片。
结论：将稳定用户偏好、会话级约束和工具执行经验分别管理，有助于提升个性化生成、多轮偏好保持以及局部编辑的可靠性。
结论支撑：受控实验显示，用户画像记忆提高了多角色、多意图条件下的 persona alignment；工具记忆在 matched-pair 诊断中改善闭环修改行为；定性案例展示了工作记忆对偏好的跨轮次保持。
局限性：工作记忆效果主要由定性案例支撑，摘要未报告端到端幻灯片质量、长期记忆污染、错误偏好遗忘以及大规模用户环境下的量化结果。
点评与适用范围：该设计可迁移到文档、网页、代码等需要长期个性化和局部修改的创作 Agent。它更偏 Agent memory 与工作流设计，而非基础模型能力创新。

In-Context World Modeling for Robotic Control

arXiv: 2606.26025 | 👍 63 | Siyin Wang, Junhao Shi, Senyu Fei, Zhaoyang Fu, Li Ji | HF
创新点：提出 In-Context World Modeling，将机器人系统辨识转化为上下文适应问题。模型利用执行任务前的短序列自主、任务无关交互推断相机视角、机器人形态和动力学等系统变量，无需更新参数。
结论：在上下文中显式建模“系统如何运作”，能够提高 VLA 策略面对未见配置时的泛化能力，尤其适用于相机视角变化。
结论支撑：论文在仿真环境和真实机器人平台上进行了实验；在新相机视角设置中，ICWM 显著优于仅依赖当前观测与语言指令的标准 VLA 基线。
局限性：摘要主要报告了相机视角变化下的收益，对机器人形态、复杂动力学变化和长时间交互的实证覆盖尚不明确；方法还需要先执行一段探索性交互，可能增加部署时延和安全风险。
点评与适用范围：适合需要快速适配新相机、设备或执行环境的具身 Agent。其价值在于把上下文窗口从“任务示例容器”扩展为“系统辨识通道”，但在安全敏感的真实机器人场景中需要约束探索行为。

🔴 NatureBench: Can Coding Agents Match the Published SOTA of Nature-Family Papers?

arXiv: 2606.24530 | 👍 62 | Yuru Wang, Lejun Cheng, Yuxin Zuo, Sihang Zeng, Bingxiang He | HF
创新点：构建包含90个跨学科真实科研任务的 NatureBench，并通过 NatureGym 自动从论文生成标准化、容器化的逐任务环境，同时引入维护方复现机制，提升科研 Agent 评测的可重复性。
结论：当前前沿 coding agents 距离稳定超越已发表科研 SOTA 仍有明显差距；现有成功更多来自将问题转化为熟悉的监督学习范式，而非真正的方法创新。
结论支撑：在禁用 Web 搜索的严格协议下评测了10种前沿 Agent 配置；最强配置按照 g>0.1 标准仅在17.8%的任务上超越 SOTA。失败分析显示，主要问题是方法选择错误和计算预算不足，而非任务理解失败。
局限性：任务来源限定于可被容器化的90篇 Nature 系论文，可能偏向具备明确代码、数据和量化指标的问题；禁用 Web 搜索有利于控制变量，但与真实科研 Agent 的工具使用方式存在差异。
点评与适用范围：适合评估科研 coding agent、自动实验系统和方法搜索能力。该工作尤其适合作为反对“单一代码修复榜单即可代表科研能力”的校准基准，但不应把榜单成绩直接等同于开放式科学发现能力。
重点理由：它以可复现的真实科研任务揭示了 coding agents 的能力边界，并用17.8%的结果量化了“完成科研任务”与“产生科学创新”之间的差距。

🔴 Agentic Abstention: Do Agents Know When to Stop Instead of Act?

arXiv: 2606.28733 | 👍 147 | Han Luo, Bingbing Wen, Lucy Lu Wang | HF
创新点：首次将 Agent 的拒绝行为形式化为序列决策问题：每一轮均需在回答、停止和继续获取信息之间选择。论文还提出 CONVOLVE，将完整交互轨迹压缩为可复用的停止规则，无需更新模型参数。
结论：当前 Agent 的主要问题不只是能否拒绝不可完成的任务，而是能否及时拒绝；更大的模型或更强的推理能力并不必然带来更好的停止判断。CONVOLVE 能显著改善及时拒绝能力。
结论支撑：在 WebShop、终端和问答环境中评测了 13 个 LLM Agent、2 种 Agent scaffold 和超过 28000 个任务。WebShop 上，CONVOLVE 将 Llama-3.3-70B 的 timely recall 从 26.7 提升至 57.4。
局限性：披露的显著提升主要来自 WebShop，跨环境迁移效果仍需验证；及时召回率不能完整反映误拒绝、任务成功率和工具成本之间的权衡；停止规则可能依赖训练轨迹的覆盖范围，并增加上下文长度。
点评与适用范围：适合用于高成本、不可逆或环境信息不完整的 Agent 系统，可作为工具调用预算控制和安全停止机制。实际部署时应联合评估误拒绝率、任务成功率与平均交互步数。
重点理由：系统定义了 Agentic Abstention 这一重要但长期被忽视的问题，并通过大规模跨环境评测证明“何时停止”是独立于模型能力的关键 Agent 可靠性指标。

🔴 Qwen-AgentWorld: Language World Models for General Agents

arXiv: 2606.24597 | 👍 146 | Yuxin Zuo, Zikai Xiao, Li Sheng, Fei Huang, Jianhong Tu | HF
创新点：构建面向通用 Agent 的语言世界模型 Qwen-AgentWorld，通过 CPT、SFT 和 RL 三阶段训练学习环境状态转移与长链推演；同时探索将世界模型作为独立环境模拟器和 Agent foundation model 训练预热器的两种路径，并提出 AgentWorldBench。
结论：语言世界模型既能低成本模拟大量 Agent 环境、扩展 Agentic RL，也能通过世界模型预训练提升统一 Agent 在下游任务上的表现。论文报告其模拟能力优于现有前沿模型，模拟环境训练的收益可超过仅使用真实环境训练。
结论支撑：训练数据包含七个领域、超过 1000 万条真实环境交互轨迹；AgentWorldBench 基于 5 个前沿模型在 9 个既有基准上的真实交互构建；世界模型预热在 7 个 Agent 基准上取得下游增益。
局限性：模型规模和数据成本较高；论文摘要未给出各基准的具体增益与模拟成本；世界模型误差可能在长轨迹中累积，并使 Agent 学会利用模拟器偏差；七个训练领域能否覆盖开放世界交互仍不确定。
点评与适用范围：适合真实环境调用昂贵、速度慢或难以大规模并发的 Agent RL 场景。使用模拟轨迹训练时应持续进行真实环境校准，并监控 simulator exploitation 和分布外状态。
重点理由：将大规模语言世界模型、环境模拟和 Agentic RL 打通，提供了减少真实环境交互成本、扩大 Agent 训练规模的一条系统性路线。

Data Journalist Agent: Transforming Data into Verifiable Multimodal Stories

arXiv: 2606.11176 | 👍 130 | Kevin Qinghong Lin, Batu EI, Yuhong Shi, Pan Lu, Philip Torr | HF
创新点：提出端到端多 Agent 虚拟编辑部 Data2Story，由不同角色协作完成数据分析、选题、叙事和多模态页面制作；Inspector 为数字、观点和素材建立到数据、代码或外部来源的证据链，并通过代码重执行验证部分陈述。
结论：多 Agent 系统可以生成具有竞争力且可审计的多媒体数据报道，在透明度和可验证性方面表现突出，但人类记者在编辑视角、创意设计和呈现质量上仍占优势，更适合作为协作工具而非替代者。
结论支撑：对 18 篇 Agent 文章及对应的人类专家文章进行配对评估；包含 53 名参与者的五维量表评价、角度覆盖分析、computer-use Agent 阅读代理评估，以及基于代码重执行和外部引用检查的可验证性测试。
局限性：样本仅有 18 篇文章，题材覆盖和统计稳定性有限；Agent judge 只是人类阅读行为的近似代理；引用存在并不等同于来源可靠；系统成本、延迟、失败恢复及真实新闻编辑流程中的长期表现尚未充分验证。
点评与适用范围：适用于数据报告、研究传播和需要审计链的内容生产。面对公共传播或高风险主题，仍需人工负责选题判断、来源可信度核验、叙事偏差检查和最终发布。

🔴 Are We Ready For An Agent-Native Memory System?

arXiv: 2606.24775 | 👍 126 | Wei Zhou, Xuanhe Zhou, Shaokun Han, Hongming Xu, Guoliang Li | HF
创新点：从数据管理系统视角拆解 Agent Memory，将其划分为表示与存储、信息抽取、检索与路由、维护四个模块，并建立覆盖效果、更新正确性、长期稳定性和运行成本的细粒度评测框架。
结论：不存在适用于所有场景的单一最优记忆架构；系统效果主要取决于记忆结构与具体工作负载瓶颈是否匹配。相比全局重组，局部维护通常具有更好的成本效益。
结论支撑：作者评测了12种代表性记忆系统和2个基线，覆盖5类工作负载与11个数据集，并通过模块消融量化表示保真度、检索精度、更新正确性及长时稳定性。
局限性：评测仍可能受底层LLM、提示词和数据集分布影响；摘要未说明对多模态记忆、多Agent共享记忆、隐私安全和超大规模并发场景的覆盖程度。
点评与适用范围：适合用于设计和选型生产级Agent记忆系统，也为RAG从静态检索走向可更新、可治理的长期记忆提供了方法论。它更像系统评测基准，而非一种包打天下的新记忆算法。

🔴 The Mirage of Optimizing Training Policies: Monotonic Inference Policies as the Real Objective for LLM Reinforcement Learning

重点理由：指出了 LLM RL 工程栈中普遍存在的目标错位：训练侧 policy 变好并不等于部署侧 policy 变好，并给出了直接面向 inference policy 的优化框架。
