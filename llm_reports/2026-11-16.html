SO-Arena: Benchmarking the Capability Spectrum and Reliability of System One Models
📅 2026-11-11 🏢 National University of Singapore Benchmark System One 评估方法 arXiv:2611.15777 HF 👍 137
创新点
针对 System One 决策模型（单次前向直接输出结构化决策、无显式推理链）提出评测基准 SO-Arena：覆盖 11 领域 2919 个任务，参考标签经人工核验且与模型可见输入对齐，按领域定制难度分层，并在 Web/工具沙箱中做交互式动作选择与任务完成验证；首次把决策可靠性（选项重排稳定性+缺失正确选项识别）作为与准确率正交维度单独量化评分。
结论
21 个模型评测显示：System Two 模型仍领先（最强 System One 落后约 10 分）；Scaling 与附加推理的收益因领域差异很大；整体能力强不等于决策可靠——能力第一名的 System One 模型可靠性仅排第七，可靠性最高者能力仅排第十一。
结论支撑
从 40 个公开数据源构建任务，人工+LLM 双重核验标签；9 个领域设难度分层，leaderboard 只计最难层；对 18 个 System One 模型测可靠性 R=√(S·N)，S 为 12 次选项重排下扣随机基线的一致率，N 为移除正确选项后基于 p_null 的 AUC 判别；延迟在 H100 上实测。指标设计有新意，可靠性干预实验控制得当。
局限性
仅覆盖选择/二元判断/评分三类决策接口，不含自由生成；难度分层只在域内校准、跨域不可比；可靠性仅测选项集合扰动，未覆盖 prompt 语义扰动；System One 生态演进快，模型名单易过时。
点评与适用范围
适合研究与评估团队借鉴其「能力-可靠性」二维评估框架，尤其做决策路由、工具选择、agent 完成验证落地的团队；重排+去正确项的可靠性测试实现成本低，可直接迁移到自有评测。基准本身是评估工具而非直接生产力。
Don't Just Trust Your Memory: Evidence-Linked Memory Reduces Memory-Induced Degradation in LLM Agents
📅 2026-11-10 🏢 KAIST LLM Agent 外部记忆 arXiv:2611.14320 HF 👍 68
创新点
系统揭示 LLM agent 外部记忆的 memory-induced degradation：52% 的退化失败可追溯到 agent 遵循的记忆条目（20% 条目本身错误，其余为越界使用、误用或忽视更优条目），根因是 lesson 仅从带成败标签的轨迹蒸馏，却不附来源轨迹，agent 无法核查。WikiTrace 将记忆组织为三层——insight（简洁经验）→ compilation（成败归因摘要）→ 原始轨迹并保持链接；测试时当 insight 细节不足、相互冲突或来自失败轨迹时，agent 用 read/bash 等终端工具沿链接下钻原始证据，修正或补全后再行动。
结论
在 5 个 agentic benchmark 的 8 个 suite 上全部排名第一：平均 90.2，较无记忆 +10.7 分，较使用相同 insight 但无证据链接的 Insights Only +3.2 分；是唯一在所有 suite 上不低于无记忆的 memory 方法；Regression 从 6.5% 降至 4.5%，甚至低于无记忆重跑基线的 9.7%。
结论支撑
覆盖 ALFWorld、ScienceWorld、PlanCraft、τ³-bench Retail、AppWorld（Normal/Challenge）八套件，统一 Pi terminal agent + deepseek-v4-flash、每配置三 trial 且记忆只构建一次；提出 Gain/Regression 分解指标替代平均准确率；失败归因用 LLM judge（与第二裁判 κ 0.77）；GLM-5.3-flash 换底座复现趋势（92.7）；测试成本仅 1.17×。Insights Only 对照有效隔离了证据链接的增量收益，实验设计严谨。
局限性
insight 仍来自只有成败标签的轨迹，下钻核查能发现矛盾但不能验证 insight 正确性；全部 insight 置于首条消息，记忆规模增大后需检索（本文未解决）；退化归因依赖 LLM judge 读推理过程，反映的是陈述而非真实因果；环境限于文本世界与工具使用，未覆盖多模态和真实长程任务。
点评与适用范围
适合建有 agent 记忆/经验复用机制的团队（工具调用、运维、RPA、办公 agent）：核心原则"lesson 必须带来源证据、可下钻核查"实现简单、成本增幅小，可直接落到现有 memory 方案上，无需改权重，落地门槛低。
Sage-Taiyi: A Metacognitive Architecture for Scientific Discovery
🔴 重点精读 📅 2026-11-09 🏢 上海人工智能实验室（Shanghai Artificial Intelligence Laboratory） AI4Science 科研智能体 arXiv:2611.12762 HF 👍 59
创新点
借鉴 Nelson & Narens 的元认知监控-控制框架，将科研搜索分为对象层与元层：对象层含 Target Tree（分解研究问题）、Idea Graph（Merge/Fuse/Diverge/Repair/Evolve 五种变换演化想法并记录谱系）、Evidence State（带来源与适用条件地记录证据）；元层含可修订的 Cognitive State（选择性表征科学理解+监测评估）与 Cognitive Repertoire（10 条方法论启发式 + 可复用 Cognitive Operators，经领域实例化与反馈学习维护）。monitoring 用搜索结果更新认知状态，control 据此选择研究目标与方法，实现"理解引导搜索"的显式闭环，而非仅依赖当前轮反馈的迭代。
结论
在 Taiyi-Bench（50 篇论文、265 个任务、10 个学科）上八项指标全部第一，Overall 53.95/54.0，较最强基线 AI Scientist-v2（47.85）高 6.1 分；ELO 1322.5，对 AI Scientist-v2 胜率 66.3%；在全部 10 个学科和 L0–L8 各信息层级均领先，且生成时间更短（29.9 分钟 vs 39.3）。AgentIdeaBench 加权分 7.195、IG-Arena PES 87.6 同样领先；5 个真实科研协作（金属催化、光化学、超材料、镁合金、离心压缩机）把提议推进到实验与 CFD 验证。
结论支撑
Taiyi-Bench 选用 2026-03-01 之后公开的研究（晚于 GPT-5.6-Sol 知识截止 2026-02-16）降低训练数据污染；文献锚定 verifier 按决策级 rubric 评分且与专家判断有较好一致性；所有系统统一 GPT-5.6-Sol（high）底座、每任务 K=10 个想法；真实案例由 Taiyi-Optimizer 做贝叶斯优化并多轮湿实验（钴催化羰基化 35 次评估把产率提到 84%；光催化烯丙基胺化 61 次评估从 13% 提到 68.7%），超材料/合金/压缩机案例给出仿真与实测指标。基准+真实实验双重支撑，设计较严谨，但 5 个案例均有专家深度参与。
局限性
评测依赖自动 verifier，历史再发现类指标对参照答案与 rubric 敏感；真实应用仅 5 个案例且专家负责选择与验证，agent 的独立贡献度难以分离；整体表现依赖 GPT-5.6-Sol 强底座，架构各组件的消融未在正文中系统给出；Taiyi-Bench 为自家构建，外部可复现性有待检验。
点评与适用范围
对 AI4Science、研发智能体、自动假设生成团队参考价值高：对象层/元层分离、可修订认知状态、方法论启发式复用库的设计可直接迁移；落地需要强底座模型与工具/优化器链支撑，中小团队可先借鉴其 monitoring-control 提示与结构，不必一次复刻全栈。🔴 重点精读理由：上海 AI Lab 大团队（署名作者 86+）的科研智能体架构：用元认知监控-控制显式调节科学搜索，在自建 Taiyi-Bench 八项指标全部第一（Overall 54.0 vs AI Scientist-v2 47.9），并完成 5 个专家协作的真实实验闭环（化学产率从微量提升至 84%、13% 至 69%），是 AI co-scientist 方向少见的"benchmark 全面领先 + 湿实验验证"工作。
Toward the Era of Agentic Embodied Intelligence
📅 2026-11-06 🏢 上海交通大学 VLA 具身智能 机器人操作 arXiv:2611.09124 HF 👍 53
创新点
提出 A2-MEAS 具身多智能体框架，以 correction code 为 scaling 接口：MetaBrain 训练期提供纠正监督、执行期提供落地引导；纠正编码器与 adapter 将纠正语言、空间证据、执行历史和动作提案吸收进动作策略权重，部署时全部权重固定、仅注入新 code 即可调整行为；底层 A2-WLA 动作模型融合 motion-aware history 与 latent world model。
结论
长时程能力应主要学习进动作模型（简单架构+动作预训练+任务特化即达 0.5755 Q、约 2.21× 2025 冠军），智能体系统在关键点做验证与纠正：100 任务 BEHAVIOR 完整系统 Q 0.6411、SR 45.40%；真实机器人 12 桌面任务 57.92% vs π0.5 的 26.67%；手冲咖啡恢复经 Adapter 从 14%/8% 提至 94%/82%。
结论支撑
三层实验：BEHAVIOR 2026 仿真 100 任务各 1000 episodes、RoboTwin 2.0 双臂 93.98%/95.05%、真实机器人 12 桌面任务与长时程手冲咖啡；组件消融显示 world model 0.4846→0.5183、motion history 加数据改进至 0.5905；训练吞吐 427.1 samples/s（4.03× π0.5 参考实现）。评测较完整，但跨版本与 2025 成绩的可比性需注意。
局限性
纠正过程需暂停执行做诊断，无法应对需即时反应的事件；纠正训练的偏差来自示范状态，与部署时真实失败状态分布不同；定量评测集中于家居仿真，真实机器人仅覆盖短程操作与咖啡制作；更多任务族、本体与环境的泛化及多次独立训练的一致性未验证。
点评与适用范围
具身智能/机器人团队可借鉴其'动作模型学长时程能力+系统在关键点纠偏'的分工与 correction code 接口设计，及 4 倍吞吐训练 infra；落地需大规模示范数据与工程投入，代码/模型/脚本计划开源，复现性较好。
Infrathon: Benchmarking Language Agents for Real-World, Long-Horizon AI Infra Optimization
📅 2026-11-09 🏢 University of Washington Infra Benchmark 智能体评测 arXiv:2611.11995 HF 👍 52
创新点
首个面向真实 AI 基础设施优化的长时程 agent benchmark：25 个任务覆盖算子/模块/系统三层，预算 12–24 小时；配套 Infrathon-build 任务构建工具与 Controller+Judge 双环境（先验任务合规再进私有评测）；累计 6 个模型×150 次运行、超 1 万 GPU 小时，并支持用 agent 运行做知识发现。
结论
前沿 agent 能在多样 infra 任务上持续改进：Claude Opus 5.5 总排名第一（平均 rank 91.2，25 任务赢 17 个）；135/150 次运行在预算后半段仍有提升，说明短时评测会漏掉增益并改变模型排名；agent 可发现超越人类设计的方案（KV 压缩 6.82×→19.86×，PSNR/SSIM/LPIPS 全面更好）；主要障碍是任务违规、不可靠测试与过早宣布完成。
结论支撑
150 次运行×12/24h 预算（H100 80GB），私有测试取预算内最佳有效分；长时程 vs 等 GPU-hour 的 best-of-n 对照显示模块/系统任务长时程更优（best-of-4 仅达系统任务的 77.3%）；KV codec 案例用 200 样本/数据集，PSNR、SSIM、LPIPS、VBench 多指标加逐样本统计验证。等预算对照、私有评测与 Controller 合规检查设计较严谨。
局限性
仅 6 个模型、25 个任务，结论对模型代际与任务集敏感；排名用相对 rank，绝对改进幅度跨任务不可比；环境为容器化单/多卡 H100，与生产集群差异大；'后半段提升'依赖 Controller 拒收与 stop hook 等框架机制；万级 GPU 小时成本难以频繁复现。
点评与适用范围
适合 agent/infra 交叉团队作为长时程 agent 能力评估与'agent 自动做算子/服务优化'的参考框架，Infrathon-build 可降低自建任务门槛；主要门槛在评测成本与 GPU 资源，普通团队可先借用其任务定义与 Controller/Judge 设计做小预算版本。
PhysLoop: Harnessing LLMs' Physics Awareness for Self-Improving Video Generation Models
📅 2026-11-12 🏢 Peking University, ByteDance Seed, Massachusetts Institute of Technology, University of California Santa Barbara 视频生成 数据构造 物理仿真 arXiv:2611.16748 HF 👍 46
创新点
提出统一 harness，让 LLM 在物理仿真器（UE/Taichi/Genesis）约束下把已有物理知识“兑现”为视频：代码智能体完成任务规格、资产检索与场景程序构建，仿真求解运动，验证器对照事件断言做物理校验，失败证据驱动迭代修正。同一套流程同时支持可控训练数据构造（PhysLoop-100K，100K 视频/2.5K 事件）与已有视频的物理错误定位修复（区间替换），是面向视频模型递归自改进（RSI）的质量控制组件。
结论
物理一致的数据与修复能显著改善视频模型的物理行为：PhysLoop-Gen 任务成功率 85%（独立 Seedance 2.5 为 73%），修复成功率 86%（最强独立基线 19%），人工评测物理合理性 4.06 vs 3.80、因果一致性 4.12 vs 3.80；外观 refinement 把视觉真实感从 2.59 提到 3.72，任务完成与外观精修起互补作用。
结论支撑
在 PhysLoop-Gen（100 任务）、PhysLoop-Repair（50 任务）、Physics-IQ Verified（66 例）三个基准上，交叉组合 GPT-6 Astra/Claude Opus 5/Kimi K3 骨干与 Seedance 2.5/MiniMax H3/Gemini Omni refiner；用人工 5 分制评分、VideoCon-Physics/VBench 自动指标与任务专属成功率。消融显示去 refiner 仍有 80% 成功、加 refiner 到 85%，说明仿真+校验环节本身有效；但自动指标与人工判断存在分歧，故仅以自动分为辅。
局限性
受仿真器、资产与验证条件覆盖限制；修复需对未观测几何/材质/初值做假设，仿真正确也未必还原真实物理；refinement 可能引入新错误，局部替换难修正已波及后续事件的错误；完整 RSI 闭环（弱点发现→数据选择→模型更新→持续增益）尚未验证，成本与误判影响需独立评估。
点评与适用范围
适合多模态/视频生成与物理数据构建团队借鉴，尤其想用“仿真校验+LLM 编排”获得可控物理训练数据的场景；作者已开源 100K 数据集、生成工具与评测基准可直接复用。落地需 UE/物理仿真工程能力与较高 API/算力成本（10 个任务约 199M token、单任务端到端 7-12 分钟），偏研究与数据基建，短期难进线上链路。
PCBRouteAgent: How Close Are LLM Agents to Becoming PCB Routing Engineers?
📅 2026-11-05 🏢 The University of Texas at Dallas, Texas Instruments, Iowa State University EDA PCB布线 工具调用 arXiv:2611.08175 HF 👍 43
创新点
提出模拟人类 PCB 工程师“全局策略+局部执行”的多模态布线智能体：Global Routing Planner 融合板图图像与结构化电气/几何信息，用 MST 生成连接拓扑、按估计线长定布线顺序、用扩展包围盒规划走廊与换层区域；Detailed Routing Executor 调 KiCad 原生 PNS 引擎执行，失败后做有界局部恢复（walkaround/shove/A* 绕行/换锚点），未解决失败以结构化反馈包返回，Planner 生成 guide patch 定向修正并保留已接受布线，形成规划-执行闭环。
结论
