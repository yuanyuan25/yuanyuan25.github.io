核心结论与阅读判断

AgentGarten 值得关注的主张是：用程序维护世界的状态和规则，用共享视频模型生成外观，再让 Agent 把交互经验写成下一轮可继承的技能文件。 这种分工让物理事件可检查、可回放，也允许同一状态轨迹更换视觉风格。

我的判断是，这篇论文最扎实的贡献集中在渲染器训练与数值执行：两遍计算恢复历史编码的梯度，逐块执行保证 replay 与采样一致，以及冻结判别器骨干条件下的精确 R1/R2。Agent 实验展示了有启发性的经验继承案例，但还不足以证明通用能力持续增长，也不能把摘要的“4 轮对比数百万次 RL”解释为同等条件下的效率倍数。论文 §3–5，PDF p.5–15

世界状态与视觉观察如何分工

程序负责状态转移

设场景程序为 ppp，状态为 sts_tst​，相机位姿为 πt\pi_tπt​，一个或多个 Agent 的动作是 ata_tat​。引擎执行状态更新，并从当前相机输出几何条件：

(st+1,πt+1)=fp(st,πt,at),ct=hp(st,πt).\begin{aligned} (s_{t+1},\pi_{t+1})&=f_p(s_t,\pi_t,a_t),\\ c_t&=h_p(s_t,\pi_t). \end{aligned}(st+1​,πt+1​)ct​​=fp​(st​,πt​,at​),=hp​(st​,πt​).​

这里的状态包含物体位姿、关节和任务变量；条件 ctc_tct​ 是相机可见的深度或表面法线。神经渲染器根据历史帧、条件、参考外观 x0x_0x0​ 与文本 yyy 生成观察：

xt=Rθ(x<t,c≤t,x0,y).x_t=R_\theta(x_{<t},c_{\leq t},x_0,y).xt​=Rθ​(x<t​,c≤t​,x0​,y).

Agent 看到 xtx_txt​ 后选择动作，动作再推进引擎。fpf_pfp​ 不把生成图像作为物理状态输入，因此纹理漂移不会直接让引擎里的箱子消失、穿墙或改变碰撞规则；渲染错误仍可能让 Agent 看错并选错动作。论文 §2.1，式 1–2，PDF p.3

推论：状态一致与观察可信是两个验收问题。 可执行状态能保证规则按代码运行，却不能保证生成图像准确表现了抓取、接触或遮挡。闭环评测应同时保留引擎事件与实际观察，分别检查“发生了什么”和“Agent 看到了什么”。

图像和文本如何变成世界

图像入口先提取实例分割、单目深度、相机内参、3D 包围盒及物体网格；coding agent 把资产放进场景，补齐未观察区域，并绑定物理属性与交互规则。文本入口直接编写几何原语和场景代码，再将初始渲染编辑为外观参考。两条路径都用探测相机、接触、碰撞余量和遮挡查询反复修正场景。论文 §2.3，图 3，PDF p.3–4

未见区域是合理的场景扩展，不能据此声称恢复了真实房间。物理可信也依赖场景程序和引擎本身：程序写错或动力学过于简化时，神经渲染不会替它纠正。

真实视频的条件由 ViPE、Depth Anything 3 和 NormalCrafter 等工具估计，模拟场景直接导出几何缓冲。法线以 (n+1)/2(n+1)/2(n+1)/2 显示；深度按 Vision Banana 的非线性映射着色：

信息论上的限制： 深度和法线不确定颜色、材质和物体身份。轴对称物体自转时，几何缓冲可能不变，表面的标记却应旋转；只给几何和有限历史，渲染器无法总是辨别这种变化。细杆、窄缝和小幅接触变化也可能在下采样后丢失。论文 §7 将更完整的条件接口列为未来工作，而不是已解决问题。

渲染器的三阶段训练

骨干和几何 token

骨干来自 Cosmos 3-Nano。理解塔 UND 冻结，将文本编码为逐层 KV；生成塔 GEN 执行视频生成。学生、教师和 fake-score 网络共享 UND 的文本结果。Wan 视频自编码器冻结，压缩时间 4 倍、空间 16 倍。

几何视频先空间池化，再用同一视频编码器和 RGB 输入投影生成条件 token：

Gt=Win P([E(S(c))]t)+egeo.G_t=W_{\mathrm{in}}\,\mathcal P\big([E(S(c))]_t\big)+e_{\mathrm{geo}}.Gt​=Win​P([E(S(c))]t​)+egeo​.

在 480×832480\times832480×832 输出下，每个 latent 帧有 390 个 RGB token、28 个几何 token。这个设计减少了条件开销，但是否优于通道拼接或 ControlNet，本文没有提供定量架构消融。为减轻真实视频估计条件与引擎条件的差异，训练随机保留深度或法线，并做双模态 dropout、纹理抑制、平滑形变和 latent 噪声扰动。附录 A.2

Exact replay 到底恢复了哪条梯度

detached KV cache 为什么会漏掉历史监督

标准 Self Forcing 把已经生成的块编码成 detached KV。后续损失可以更新“如何读取这个 KV 并预测当前块”，却无法通过这份 cache 更新“怎样把历史图像编码成 KV”。如果让完整多步、自回归 rollout 全部保留计算图，显存又很昂贵。

AgentGarten 分两遍执行：第一遍不建梯度图，记录每个块最后一次去噪的输入 UjU_jUj​ 与干净输出 ZjZ_jZj​；第二遍重新编码已录制的历史，并重算最后一步：

z~θ,j=sg⁡(Uj)−t∗vθ(sg⁡(Uj),t∗∣sg⁡(Z<j),C;MTF).\widetilde z_{\theta,j}=\operatorname{sg}(U_j)-t^*v_\theta\left( \operatorname{sg}(U_j),t^*\mid\operatorname{sg}(Z_{<j}),\mathcal C;\mathcal M_{\mathrm{TF}}\right).zθ,j​=sg(Uj​)−t∗vθ​(sg(Uj​),t∗∣sg(Z<j​),C;MTF​).

历史图像 Z<jZ_{<j}Z<j​ 本身 detached，但第二遍的 history encoder 参数仍在图内。因此后续损失能沿着“当前输出 → 历史 KV → 历史编码参数”回传。论文 §3.4.2，式 8，PDF p.6–7

一个简化的链式求导有助于区分：设重新计算的历史 KV 为 Kθ(Z)K_\theta(Z)Kθ​(Z)、Vθ(Z)V_\theta(Z)Vθ​(Z)，当前预测为 Fθ(U,K,V)F_\theta(U,K,V)Fθ​(U,K,V)，那么

dFdθ=∂F∂θ∣K,V+∂F∂K∂Kθ(Z)∂θ+∂F∂V∂Vθ(Z)∂θ.\frac{dF}{d\theta}=\left.\frac{\partial F}{\partial\theta}\right|_{K,V} +\frac{\partial F}{\partial K}\frac{\partial K_\theta(Z)}{\partial\theta} +\frac{\partial F}{\partial V}\frac{\partial V_\theta(Z)}{\partial\theta}.dθdF​=∂θ∂F​​K,V​+∂K∂F​∂θ∂Kθ​(Z)​+∂V∂F​∂θ∂Vθ​(Z)​.

后两项就是 cache detach 时丢失的路径；因为 ZZZ 固定，这里不包含 ∂Z/∂θ\partial Z/\partial\theta∂Z/∂θ。恢复历史编码梯度不等于对全部历史生成、多步采样轨迹做完整 BPTT。

为什么同一个 attention mask 还不够

SGF 风格 replay 用一次 full-sequence FlexAttention，而 rollout 使用逐块 cache。实数运算下相同 mask 可以表达相同函数；BF16 下，kernel、张量形状、矩阵分组与归约顺序变化会产生舍入差异，并被深层网络放大。

论文的 exact replay 逐块使用 SDPA，对齐可见上下文、KV 顺序、调用形状、投影与 FFN 分组。历史 KV 在第二遍重新计算，不能直接拿第一遍 detached cache 顶替。每块实际包含 noisy query 和 clean publication 两次 attention 调用。论文图 5、附录 A.4

对抗监督与精确 R1/R2 推导

为什么在 DMD 之外加真实数据监督

DMD 使用教师与 fake-score 对生成样本的估计；对抗项直接比较真实和生成视频。判别器 Dϕ(x)=hϕ(B(x))D_\phi(x)=h_\phi(B(x))Dϕ​(x)=hϕ​(B(x)) 使用冻结教师骨干 BBB 的第 11、23、35 层特征，以及可训练聚合 head hϕh_\phihϕ​。真实和生成 clip 在同条件、同噪声、同 timestep 下得到 logits r,fr,fr,f：

LG=E[softplus⁡(sg⁡(r)−f)],Lrel=E[softplus⁡(f−r)],Lstudent=LDMD+λGLG.\begin{aligned} \mathcal L_G&=\mathbb E[\operatorname{softplus}(\operatorname{sg}(r)-f)],\\ \mathcal L_{\mathrm{rel}}&=\mathbb E[\operatorname{softplus}(f-r)],\\ \mathcal L_{\mathrm{student}}&=\mathcal L_{\mathrm{DMD}}+\lambda_G\mathcal L_G. \end{aligned}LG​Lrel​Lstudent​​=E[softplus(sg(r)−f)],=E[softplus(f−r)],=LDMD​+λG​LG​.​

生成器更新推动 fake logit 超过 real；判别器更新推动 real 超过 fake。生成器端的对抗梯度通过线性 surrogate 注入 replay，避免保留整段 rollout 的图。论文 §3.4.3，式 9，附录 A.4

冻结骨干为何能绕过 attention double backward

R1/R2 是真实/生成输入上的判别器输入梯度平方。通常要对输入梯度再求参数梯度，融合 attention 的 backward 未必支持再次求导。论文利用 BBB 冻结、只训练 hϕh_\phihϕ​ 的条件，改用 VJP 与 JVP。

对单个样本，令 z=B(x)z=B(x)z=B(x)、A=JB(x)A=J_B(x)A=JB​(x)、u=∇zhϕ(z)u=\nabla_z h_\phi(z)u=∇z​hϕ​(z)。先反向计算输入梯度，再前向传播这个方向：

g=A⊤u=∇xDϕ(x),R=g⊤g=u⊤AA⊤u,v=Ag=AA⊤u.\begin{aligned} g&=A^\top u=\nabla_x D_\phi(x),\\ R&=g^\top g=u^\top AA^\top u,\\ v&=Ag=AA^\top u. \end{aligned}gRv​=A⊤u=∇x​Dϕ​(x),=g⊤g=u⊤AA⊤u,=Ag=AA⊤u.​

因为 z,Az,Az,A 与 head 参数 ϕ\phiϕ 无关，逐步求导得到：

∇ϕR=2(∂u∂ϕ)⊤AA⊤u=2(∂u∂ϕ)⊤v=∇ϕ[2Jzhϕ(z)sg⁡(v)].\begin{aligned} \nabla_\phi R &=2\left(\frac{\partial u}{\partial\phi}\right)^\top AA^\top u\\ &=2\left(\frac{\partial u}{\partial\phi}\right)^\top v\\ &=\nabla_\phi\left[2J_z h_\phi(z)\operatorname{sg}(v)\right]. \end{aligned}∇ϕ​R​=2(∂ϕ∂u​)⊤AA⊤u=2(∂ϕ∂u​)⊤v=∇ϕ​[2Jz​hϕ​(z)sg(v)].​

把方向在当前参数处计算后 detach，令 s=2Jzhϕ(z)sg⁡(v)s=2J_z h_\phi(z)\operatorname{sg}(v)s=2Jz​hϕ​(z)sg(v)，构造：

R~=sg⁡(g⊤g)+s−sg⁡(s).\widetilde R=\operatorname{sg}(g^\top g)+s-\operatorname{sg}(s).R=sg(g⊤g)+s−sg(s).

前向时 s−sg⁡(s)=0s-\operatorname{sg}(s)=0s−sg(s)=0，因此值是原始 penalty；反向只走 sss，因此 head 的一阶参数梯度与真正的 RRR 一致。对真实和 detached 生成样本分别计算即可得到 R1/R2。判别器目标为

LD=λD(Lrel+γ2(R~1+R~2)).\mathcal L_D=\lambda_D\left(\mathcal L_{\mathrm{rel}}+\frac\gamma2(\widetilde R_1+\widetilde R_2)\right).LD​=λD​(Lrel​+2γ​(R1​+R2​)).

适用边界： 骨干可以非线性，但必须冻结；每次更新都要重新计算方向；该 surrogate 不提供任意高阶导数的替代图。head 的混合二阶导数在数学上仍存在，绕过的是大型融合 attention 的 backward-over-backward。论文式 10–13，附录 B，PDF p.7–8、22–23

公开代码还值得注意：当前 exact_regularization.py 用冻结骨干的 forward-mode JVP，再用 autograd.grad(..., create_graph=True) 计算小 head 的梯度；这与论文描述的显式 head 方向导数实现路径有差别，但同样把 double backward 限制在 head 上。不能笼统写成“完全不需要二阶导数”。

服务端保留 reference 与 sink prefix，加上最近历史的滑动窗口。默认配置为 5 个 sink latent 帧、44 个 recent latent 帧，每次生成 4 个 latent 帧，对应 16 个像素帧。旧帧的 RGB 与几何 KV 同时淘汰。超过训练长度时，当前块 RoPE 起点限制为 min⁡(s,H−b)\min(s,H-b)min(s,H−b)，recent history 移到它前面并重新旋转 key；condition 内容仍按实际模拟时间索引。论文 §3.5、附录 C，PDF p.8、23

Agent 如何通过 playbook 改进

实践轮开始时，Agent 获得 task file，知道目标、动作接口与预算；随后观察神经生成 RGB，执行动作，结束后写下尝试、观察、失败、不确定性和下一步。下一轮用新会话启动，读取原任务与此前手册。捉迷藏两方各自维护一课一个文件的技能库，文件可以含代码。论文 §5.2–5.3，PDF p.11、13–14

因此经验保存在外部文本，而非 Agent 权重更新。论文参考文献 [32] 将预训练 Agent 指向 GPT-6 Astra；这还不足以完整恢复模型服务版本、推理预算、系统提示和工具包装。coding agent 创建世界与 acting agent 在世界里执行任务也应区分。

证据强度与适用范围

哪些结论还需要对照实验

  1. playbook 的因果收益。 当前结果缺少同模型、同 seed、同预算的无手册、通用反思和打乱手册对照。改善可能同时来自经验继承、布局变化或生成随机性。
  2. Adversarial Forcing 各组件的贡献。 图 8 对比的是组合方法和 Self Forcing，无法分别确定历史梯度、精确执行和 GAN 对画质的增益。还需要量化几何跟随、身份保持、遮挡后恢复和长时漂移。
  3. 神经外观对任务的价值。 需要固定状态轨迹比较常规 RGB、神经 RGB 与诊断几何条件。更漂亮的画面可能帮助预训练视觉模型，也可能遮蔽关键接触信息。
  4. 跨世界泛化。 已展示的手册属于各自世界；未见世界成功率、长期知识检索、错误经验清除和自动课程增长还没有构成统计性证据。

这些是基于论文实验设计的研究判断，不是作者已报告的负结果。本文有可运行方向与案例价值，但整体证据更接近系统技术报告，不能读成完整的通用 Agent 学习 benchmark。

适合迁移的场景

适合状态可以显式编程、视觉主要由几何决定、动作容许按块执行的环境，例如布局导航、工具使用和多 Agent 协作原型。同一状态轨迹换风格特别适合做视觉鲁棒性实验。精确 replay 也适用于其他依赖自生成历史 KV 的自回归视频蒸馏；R1/R2 推导则适用于冻结大骨干、训练小判别 head 的架构。

对高速反馈控制、细接触操作、必须识别材质/身份/自转的任务，当前几何接口和动作节奏都有明显限制。狭桥 task file 允许车辆原地转向，明确是简化控制；装载机使用低速有限力转弯。这些合成任务的成绩不能直接转成真实车辆或机器人能力证据。附录 D，PDF p.24–26

对现有游戏 Agent 实验的启发

以下是研究建议，不属于论文结果；本次未启动新实验，也不改变当前项目优先级。

对推箱子等可执行规则明确的环境，最先值得借鉴的是 验证经验继承是否提高未见关卡成功率。这不需要先接入昂贵的神经渲染。现有模拟器已经可以提供状态裁判和 RGB 观察，把视觉链路稳定下来之后，再分别研究记忆和外观变化。

最小实验 冻结的比较条件 回答的问题
无手册 / 通用反思 / 经验手册 / 打乱手册 同底模、held-out 关卡、动作接口、观察、token 与动作预算；每局新会话 收益是否来自可迁移经验，而非多尝试或提示长度
验证手册 / 未验证手册 仅训练布局可用于实践与经验验证；测试布局不写回记忆 错误经验传播是否限制跨轮改进
原始 RGB / 改变外观 RGB 固定引擎状态、动作、相机和评测关卡 视觉先验与外观干扰各占多少
固定动作轨迹的多外观回放 完全相同底层事件，比较动作识别与闭环测试 区分观察变化与动力学变化

主指标应是未见关卡通关率、死锁率、有效动作数和预算耗尽率，并保存引擎事件与实际截图；文字手册可以提出假设，但须通过重放或多布局验证才进入长期技能库。静态动作标签准确率只能描述局部预测，不能替代闭环成绩。若这些低成本实验显示稳定收益，再考虑神经渲染与自动生成世界。
