激活函数：SiLU 与 SwiGLU

本文目录 4 个章节 · 展开查看
1. SiLU 的定义2. 与 ReLU 比较3. SwiGLU 的定义与参数量4. 来源

先区分两个层级：SiLU 是作用于单个数值的非线性函数；SwiGLU 是由可学习投影、SiLU 和逐元素乘法组成的 MLP 模块。

1. SiLU 的定义

对于一个输入标量 xxx，先定义 sigmoid σ(x)\sigma(x)σ(x)，它输出一个介于 0 与 1 之间的值；再让这个值与输入 xxx 相乘，得到 SiLU：

σ(x)=11+e−x,SiLU⁡(x)=xσ(x).\sigma(x)=\frac{1}{1+e^{-x}},\qquad \operatorname{SiLU}(x)=x\sigma(x).σ(x)=1+e−x1​,SiLU(x)=xσ(x).

SiLU 是平滑的自门控函数：门值由输入自身通过 sigmoid 产生。Swish 一般写为 xσ(βx)x\sigma(\beta x)xσ(βx)，取 β=1\beta=1β=1 时与 SiLU 相同。

“自门控”可以这样理解：由输入自己生成一个连续的门值，再用它调节自己的幅度。较大的正输入通常大部分通过，较负输入被明显压低；这不是额外引入一组门控参数。

为了判断梯度怎样流动，先使用 sigmoid 的导数 σ′(x)=σ(x)(1−σ(x))\sigma'(x)=\sigma(x)(1-\sigma(x))σ′(x)=σ(x)(1−σ(x))，再对 xσ(x)x\sigma(x)xσ(x) 使用乘积求导法则：

SiLU⁡′(x)=1⋅σ(x)+xσ′(x)=σ(x)+xσ(x)(1−σ(x)).\begin{aligned} \operatorname{SiLU}'(x) &=1\cdot\sigma(x)+x\sigma'(x)\\ &=\sigma(x)+x\sigma(x)(1-\sigma(x)). \end{aligned}SiLU′(x)​=1⋅σ(x)+xσ′(x)=σ(x)+xσ(x)(1−σ(x)).​

曲线与公式一致：负区间存在轻微下凹，不是单调函数。导数在约 x=−1.278x=-1.278x=−1.278 处为零，在很负的位置也会趋近于零，因此不能说“负区间始终有非零梯度”。

2. 与 ReLU 比较

ReLU⁡(x)=max⁡(0,x).\operatorname{ReLU}(x)=\max(0,x).ReLU(x)=max(0,x).

ReLU 在负半轴的导数为零；若某个单元对相关输入长期落入负区间，可能难以通过自己的局部梯度恢复。但其他参数、输入分布与优化器状态的变化仍可能改变其输入，不能绝对说“一旦死亡永不恢复”。

SiLU 没有整段负半轴恒零的梯度区间，有助于缓解这一现象；平滑性不自动保证更稳定或更快收敛。性能取决于架构、初始化、训练设置与硬件，不能把某类 Transformer 上的经验推广到所有网络。

3. SwiGLU 的定义与参数量

设 XXX 是 token 表示矩阵，输入宽度为 HHH，中间特征宽度为 III。我们定义三个可学习投影：WgW_gWg​ 生成 gate 分支，WuW_uWu​ 生成 up 分支，WdW_dWd​ 将中间结果映射回宽度 HHH。采用行向量记号、忽略偏置时：

G=SiLU⁡(XWg),U=XWu,Y=(G⊙U)Wd.G=\operatorname{SiLU}(XW_g),\qquad U=XW_u, \qquad Y=(G\odot U)W_d.G=SiLU(XWg​),U=XWu​,Y=(G⊙U)Wd​.

这里 GGG 是经过 SiLU 的 gate 分支表示，UUU 是 up 分支表示；二者形状相同，⊙\odot⊙ 表示逐元素相乘，让一条分支调节另一条分支的特征。再经过 down 投影得到输出 YYY。注意 SiLU 的输出并不被限制在 0 到 1，不能把整个 GGG 当成概率。

两个上投影 Wg,Wu∈RH×IW_g,W_u\in\mathbb R^{H\times I}Wg​,Wu​∈RH×I，下投影 Wd∈RI×HW_d\in\mathbb R^{I\times H}Wd​∈RI×H，因此参数数目为 HI+HI+IHHI+HI+IHHI+HI+IH：

PSwiGLU=3HI.P_{\rm SwiGLU}=3HI.PSwiGLU​=3HI.

这里 gate_proj 和 up_proj 的矩阵都是可学习参数。SiLU 的“自门控”不表示整个 SwiGLU 没有可学习的门控投影。
