这篇笔记沿着一个问题展开：已有“回答 A 比回答 B 更好”的偏好数据，怎样让语言模型更愿意生成好的回答？先看 RLHF 如何先学打分、再优化生成策略，再推导 DPO 怎样把这两步合成一个训练目标。

DPO（Direct Preference Optimization）直接用偏好对训练策略，标准离线 DPO 不需要另外训练显式 RM，也不需要在优化循环中运行 PPO。DPO 得到的是生成模型；它与固定 reference 一起可以定义一个隐式奖励函数。

1. 模型角色与符号

对于同一个问题 xxx，语言模型可能生成许多不同回答。我们用策略 π(y∣x)\pi(y\mid x)π(y∣x) 表示“看到 xxx 后生成完整回答 yyy 的概率”。策略由语言模型实现；改变模型参数，就是改变这些回答的概率分布。

奖励函数 r(x,y)r(x,y)r(x,y) 则给一个已经确定的“问题—回答”组合打分。它输出一个实数，分数高表示模型判断这个回答更值得鼓励。生成概率回答“会不会说”，奖励分数回答“有多值得鼓励”，两者承担不同角色。

2. Bradley–Terry 偏好模型

4. RLHF 的 KL 正则化目标

RLHF 的第二步才开始训练生成模型：先固定已经学好的奖励模型，让待训练策略 π\piπ 生成回答，再根据 RM 给出的分数调整策略。为了不让模型只顾迎合 RM、过度偏离原本的语言能力，还要保留一个冻结的参考策略 πref\pi_{\rm ref}πref​。

我们定义 Dx\mathcal D_xDx​ 为训练时抽取问题的分布，Jr(π)J_r(\pi)Jr​(π) 为希望最大化的策略目标。外层先从 Dx\mathcal D_xDx​ 抽问题 xxx，内层再让当前策略生成回答 yyy：

5. KL 散度与期望

5.1 先定义离散 KL

先暂时离开语言模型，考虑同一个取值集合 Z\mathcal ZZ 上的两个离散概率分布 PPP 和 QQQ。zzz 表示其中一个可能的结果，P(z)P(z)P(z)、Q(z)Q(z)Q(z) 表示两个分布分别给这个结果分配的概率。我们定义从 PPP 到 QQQ 的 KL 散度为：

DKL(P∥Q)=∑z∈ZP(z)log⁡P(z)Q(z).D_{\rm KL}(P\Vert Q)=\sum_{z\in\mathcal Z}P(z)\log\frac{P(z)}{Q(z)}.DKL​(P∥Q)=z∈Z∑​P(z)logQ(z)P(z)​.

这个式子本质上是加权求和：对于每个结果 zzz，先算对数概率比 log⁡[P(z)/Q(z)]\log[P(z)/Q(z)]log[P(z)/Q(z)]，再乘以结果在 PPP 下出现的概率 P(z)P(z)P(z)，最后遍历所有结果相加。因此，比较的数值来自两个分布，权重则始终来自 PPP。

5.2 把对数概率比视为随机变量

为了把这个加权和写成期望，我们引入随机变量 ZZZ，让它服从分布 PPP，记作 Z∼PZ\sim PZ∼P。大写 ZZZ 表示还没有抽样的随机结果，小写 zzz 表示它的一种具体取值。

接着定义函数 g(z)=log⁡[P(z)/Q(z)]g(z)=\log[P(z)/Q(z)]g(z)=log[P(z)/Q(z)]：输入一个结果 zzz，输出两个分布在该结果上的对数概率比。因为输入 ZZZ 是随机的，U=g(Z)U=g(Z)U=g(Z) 也成为一个随机变量。它不再表示“抽中了哪个结果”，而表示“抽中这个结果后得到多大的对数比”。

例如，若 PPP 给两个结果的概率为 0.8 和 0.2，而 QQQ 都给 0.5，那么 UUU 分别以 0.8、0.2 的概率取值 log⁡(0.8/0.5)\log(0.8/0.5)log(0.8/0.5)、log⁡(0.2/0.5)\log(0.2/0.5)log(0.2/0.5)。它的期望就是这两个数按出现概率加权的平均值。一般地，按照离散随机变量的期望定义：

EZ∼P[U]=∑z∈ZP(z)g(z)=∑z∈ZP(z)log⁡P(z)Q(z).\begin{aligned} \mathbb E_{Z\sim P}[U] &=\sum_{z\in\mathcal Z}P(z)g(z)\\ &=\sum_{z\in\mathcal Z}P(z)\log\frac{P(z)}{Q(z)}. \end{aligned}EZ∼P​[U]​=z∈Z∑​P(z)g(z)=z∈Z∑​P(z)logQ(z)P(z)​.​

第一步枚举 ZZZ 的每种取值：取到 zzz 的概率是 P(z)P(z)P(z)，这时 UUU 的数值是 g(z)g(z)g(z)，所以两者相乘后求和。第二步只是把 g(z)g(z)g(z) 换回刚才定义的对数比，没有新增假设。

5.3 识别为同一个加权和

现在比较第 5.1 节与刚得到的式子，会发现两边是完全相同的加权和。因此可以把 KL 散度写成下面的期望形式：

DKL(P∥Q)=EZ∼P[log⁡P(Z)Q(Z)].D_{\rm KL}(P\Vert Q) =\mathbb E_{Z\sim P}\left[\log\frac{P(Z)}{Q(Z)}\right].DKL​(P∥Q)=EZ∼P​[logQ(Z)P(Z)​].

用于语言模型时，固定 prompt xxx，把随机变量换成回答 Y∼π(⋅∣x)Y\sim\pi(\cdot\mid x)Y∼π(⋅∣x)：

DKL(π∥πref)=EY∼π(⋅∣x)log⁡π(Y∣x)πref(Y∣x).D_{\rm KL}(\pi\Vert\pi_{\rm ref}) =\mathbb E_{Y\sim\pi(\cdot\mid x)} \log\frac{\pi(Y\mid x)}{\pi_{\rm ref}(Y\mid x)}.DKL​(π∥πref​)=EY∼π(⋅∣x)​logπref​(Y∣x)π(Y∣x)​.

6. 从 RL 目标得到最优策略

接下来求解第 4 节的目标。先固定一个问题 xxx，把奖励函数 rrr 和参考策略 πref\pi_{\rm ref}πref​ 都视为给定；唯一要寻找的是回答分布 π(⋅∣x)\pi(\cdot\mid x)π(⋅∣x)。我们把这个问题上的目标记作 Jr(π∣x)J_r(\pi\mid x)Jr​(π∣x)，省去外层问题平均，先回答“对于这一个问题，怎样分配回答概率最好”。

推导的思路是把目标整理成 KL 散度。只要得到“一个常数减去 KL”的形式，就可以利用 KL 非负来判断哪种回答分布最优。

6.1 展开 KL，并合并期望

利用第 5 节的等式：

Jr(π∣x)=Ey∼πr(x,y)−βEy∼πlog⁡π(y∣x)πref(y∣x)=Ey∼π[r(x,y)−βlog⁡π(y∣x)πref(y∣x)].\begin{aligned} J_r(\pi\mid x) &=\mathbb E_{y\sim\pi}r(x,y)-\beta\mathbb E_{y\sim\pi}\log\frac{\pi(y\mid x)}{\pi_{\rm ref}(y\mid x)}\\ &=\mathbb E_{y\sim\pi}\left[r(x,y)-\beta\log\frac{\pi(y\mid x)}{\pi_{\rm ref}(y\mid x)}\right]. \end{aligned}Jr​(π∣x)​=Ey∼π​r(x,y)−βEy∼π​logπref​(y∣x)π(y∣x)​=Ey∼π​[r(x,y)−βlogπref​(y∣x)π(y∣x)​].​

两项都对同一策略采样的回答取期望，所以可以合并。

6.3 分母尚未归一化，引入 Z

观察刚得到的分母：对于固定问题 xxx，它给每条回答 yyy 一个正权重。我们将这个权重定义为 wx(y)=πref(y∣x)er(x,y)/βw_x(y)=\pi_{\rm ref}(y\mid x)e^{r(x,y)/\beta}wx​(y)=πref​(y∣x)er(x,y)/β。其中 reference 提供初始概率，指数项按奖励调整权重：奖励较高的回答得到更大的乘数。

这些权重相加未必等于 1，所以还不能直接叫概率。为了把它们构造成分布，我们定义配分函数 Z(x)Z(x)Z(x)，也就是这个问题下所有回答权重的总和：

Z(x)=∑ywx(y)=∑yπref(y∣x)er(x,y)/β.\begin{aligned} Z(x) &=\sum_y w_x(y)\\ &=\sum_y\pi_{\rm ref}(y\mid x)e^{r(x,y)/\beta}. \end{aligned}Z(x)​=y∑​wx​(y)=y∑​πref​(y∣x)er(x,y)/β.​

这里的 Z(x)Z(x)Z(x) 是依赖问题 xxx 的归一化常数，与上一节用大写 ZZZ 表示的随机变量是不同对象；后面都按函数 Z(x)Z(x)Z(x) 使用。在 0<Z(x)<∞0<Z(x)<\infty0<Z(x)<∞ 的条件下，将每个权重除以同一个总和，定义新的回答分布 π∗\pi^*π∗：

π∗(y∣x)=wx(y)Z(x),∑yπ∗(y∣x)=∑ywx(y)Z(x)=1.\begin{aligned} \pi^*(y\mid x) &=\frac{w_x(y)}{Z(x)},\\[4pt] \sum_y\pi^*(y\mid x) &=\frac{\sum_yw_x(y)}{Z(x)}\\ &=1. \end{aligned}π∗(y∣x)y∑​π∗(y∣x)​=Z(x)wx​(y)​,=Z(x)∑y​wx​(y)​=1.​

式子右侧的求和验证了新分布的概率之和确实为 1。此时星号只是给这个候选分布起名；下一步把它代回目标，才证明它为什么最优。

6.4 代回目标，拆出与策略无关的常数

因为 wx(y)=Z(x)π∗(y∣x)w_x(y)=Z(x)\pi^*(y\mid x)wx​(y)=Z(x)π∗(y∣x)，所以：

第一行用 Z(x)π∗(y∣x)Z(x)\pi^*(y\mid x)Z(x)π∗(y∣x) 替换 wx(y)w_x(y)wx​(y)；第二行用对数的商法则，把归一化常数拆出来。对于同一个问题，所有回答对应同一个 Z(x)Z(x)Z(x)，所以第三行可以把 log⁡Z(x)\log Z(x)logZ(x) 提到回答期望之外。最后一行认出剩余期望正是 DKL(π∥π∗)D_{\rm KL}(\pi\Vert\pi^*)DKL​(π∥π∗)。

还要注意：这里 rrr 与 reference 都固定，因此 Z(x)Z(x)Z(x) 也不依赖正在优化的 π\piπ。这才允许我们在寻找最优策略时将它视作常数。

6.5 用 KL 非负性得到最优策略

还原 J=−βFJ=-\beta FJ=−βF，得到严格的目标值恒等式：

Jr(π∣x)=βlog⁡Z(x)−βDKL(π∥π∗).J_r(\pi\mid x)=\beta\log Z(x)-\beta D_{\rm KL}(\pi\Vert\pi^*).Jr​(π∣x)=βlogZ(x)−βDKL​(π∥π∗).

KL 非负，且在两个分布相同时为零，因此：

arg⁡max⁡πJr(π∣x)=arg⁡min⁡πDKL(π∥π∗)=π∗,max⁡πJr(π∣x)=βlog⁡Z(x).\begin{aligned} \arg\max_\pi J_r(\pi\mid x) &=\arg\min_\pi D_{\rm KL}(\pi\Vert\pi^*)\\ &=\pi^*,\\[4pt] \max_\pi J_r(\pi\mid x) &=\beta\log Z(x). \end{aligned}argπmax​Jr​(π∣x)πmax​Jr​(π∣x)​=argπmin​DKL​(π∥π∗)=π∗,=βlogZ(x).​

再对固定 prompt 分布取期望，只把常数换成 βExlog⁡Z(x)\beta\mathbb E_x\log Z(x)βEx​logZ(x)；逐 prompt 的最优分布不变。这是分布空间中的理想解，有限模型、有限数据与优化误差仍可能使实际训练结果偏离它。

7. 从最优策略重参数化奖励

前面是在“已知奖励”的条件下求最优生成分布。DPO 接着反过来使用这个关系：既然奖励能决定最优策略，能否用策略概率来表示奖励，再直接训练策略去解释偏好数据？这样，第 3 节本来用来训练 RM 的偏好目标，就能改写为训练语言模型的目标。

7.1 从最优策略反解奖励

将第 6 节的式子两边除以 reference，再取对数：

π∗(y∣x)πref(y∣x)=er(x,y)/βZ(x),log⁡π∗(y∣x)πref(y∣x)=r(x,y)β−log⁡Z(x),r(x,y)=βlog⁡π∗(y∣x)πref(y∣x)+βlog⁡Z(x).\begin{aligned} \frac{\pi^*(y\mid x)}{\pi_{\rm ref}(y\mid x)}&=\frac{e^{r(x,y)/\beta}}{Z(x)},\\ \log\frac{\pi^*(y\mid x)}{\pi_{\rm ref}(y\mid x)}&=\frac{r(x,y)}{\beta}-\log Z(x),\\ r(x,y)&=\beta\log\frac{\pi^*(y\mid x)}{\pi_{\rm ref}(y\mid x)}+\beta\log Z(x). \end{aligned}πref​(y∣x)π∗(y∣x)​logπref​(y∣x)π∗(y∣x)​r(x,y)​=Z(x)er(x,y)/β​,=βr(x,y)​−logZ(x),=βlogπref​(y∣x)π∗(y∣x)​+βlogZ(x).​

7.2 对同一个 prompt 作奖励差，常数相消

对于同一个问题的两条回答，我们分别定义 aw=log⁡[π∗(yw∣x)/πref(yw∣x)]a_w=\log[\pi^*(y_w\mid x)/\pi_{\rm ref}(y_w\mid x)]aw​=log[π∗(yw​∣x)/πref​(yw​∣x)] 和 al=log⁡[π∗(yl∣x)/πref(yl∣x)]a_l=\log[\pi^*(y_l\mid x)/\pi_{\rm ref}(y_l\mid x)]al​=log[π∗(yl​∣x)/πref​(yl​∣x)]。这两个记号只为缩短接下来的式子，分别表示优选回答、非优选回答相对 reference 的对数概率比。它们不是 PPO 的 advantage。

r(x,yw)−r(x,yl)=[βaw+βlog⁡Z(x)]−[βal+βlog⁡Z(x)]=βaw−βal.\begin{aligned} r(x,y_w)-r(x,y_l) &=[\beta a_w+\beta\log Z(x)]-[\beta a_l+\beta\log Z(x)]\\ &=\beta a_w-\beta a_l. \end{aligned}r(x,yw​)−r(x,yl​)​=[βaw​+βlogZ(x)]−[βal​+βlogZ(x)]=βaw​−βal​.​

两条回答必须对应同一 xxx，才能消掉同一个 Z(x)Z(x)Z(x)；这一步没有把两个回答的生成概率直接作差。

7.3 先代入偏好概率，再代入 RM 似然

先在 Bradley–Terry 中替换奖励差：

P(yw≻yl∣x)=σ ⁣(βlog⁡π∗(yw∣x)πref(yw∣x)−βlog⁡π∗(yl∣x)πref(yl∣x)).P(y_w\succ y_l\mid x) =\sigma\!\left(\beta\log\frac{\pi^*(y_w\mid x)}{\pi_{\rm ref}(y_w\mid x)} -\beta\log\frac{\pi^*(y_l\mid x)}{\pi_{\rm ref}(y_l\mid x)}\right).P(yw​≻yl​∣x)=σ(βlogπref​(yw​∣x)π∗(yw​∣x)​−βlogπref​(yl​∣x)π∗(yl​∣x)​).

现在偏好概率只需要策略与 reference 的概率，就能计算出来。把它放回第 3 节的最大化对数似然，优化变量便从显式奖励函数转向了表示它的策略分布：

7.4 用可训练策略参数化，改写成最小化 loss

把理论分布参数化为 πθ\pi_\thetaπθ​，再给整个最大化目标取负号：

LDPO(θ)=−E(x,yw,yl)∼Dlog⁡σ(βlog⁡πθ(yw∣x)πref(yw∣x)−βlog⁡πθ(yl∣x)πref(yl∣x)).\mathcal L_{\rm DPO}(\theta) =-\mathbb E_{(x,y_w,y_l)\sim\mathcal D} \log\sigma\left( \beta\log\frac{\pi_\theta(y_w\mid x)}{\pi_{\rm ref}(y_w\mid x)} -\beta\log\frac{\pi_\theta(y_l\mid x)}{\pi_{\rm ref}(y_l\mid x)} \right).LDPO​(θ)=−E(x,yw​,yl​)∼D​logσ(βlogπref​(yw​∣x)πθ​(yw​∣x)​−βlogπref​(yl​∣x)πθ​(yl​∣x)​).

这样，BT 模型、偏好数据和极大似然的含义都保留下来，而训练对象变成了生成模型。这不是假设每次更新中的 πθ\pi_\thetaπθ​ 都已等于理想最优策略。

8. 隐式奖励到底是什么

把训练完成的策略记作 πDPO\pi_{\rm DPO}πDPO​。现在给定任意问题 xxx 和一条确定的回答 yyy，冻结 DPO 模型与 reference，让二者对同一串回答 token 计算概率，而不是各自再生成一条新回答。由这两个概率，我们定义隐式奖励：

r^(x,y)=β[log⁡πDPO(y∣x)−log⁡πref(y∣x)],\hat r(x,y)=\beta\left[\log\pi_{\rm DPO}(y\mid x)-\log\pi_{\rm ref}(y\mid x)\right],r^(x,y)=β[logπDPO​(y∣x)−logπref​(y∣x)],
log⁡π(y∣x)=∑t=1∣y∣log⁡π(yt∣x,y<t).\log\pi(y\mid x)=\sum_{t=1}^{|y|}\log\pi(y_t\mid x,y_{<t}).logπ(y∣x)=t=1∑∣y∣​logπ(yt​∣x,y<t​).

其中 yty_tyt​ 是回答的第 ttt 个 token，y<ty_{<t}y<t​ 是此前的回答前缀；序列概率按自回归分解为每步条件概率的乘积，取对数后就是上面的逐 token 求和。计算时通常直接累加 log-prob，避免完整序列概率相乘后过小。

这是标量奖励分数，可以为负，也可以大于 1，不是概率。标准序列 log-prob 使用回答 token 的求和；若改为长度平均，就改变了奖励定义。打分需统一 tokenizer、prompt 模板、回答边界与 EOS 约定。

概率比 隐式奖励（β>0\beta>0β>0） 含义
πDPO/πref>1\pi_{\rm DPO}/\pi_{\rm ref}>1πDPO​/πref​>1 正 相对 reference，该回答的概率被增强
πDPO/πref=1\pi_{\rm DPO}/\pi_{\rm ref}=1πDPO​/πref​=1 零 概率不变
πDPO/πref<1\pi_{\rm DPO}/\pi_{\rm ref}<1πDPO​/πref​<1 负 相对 reference，该回答被抑制

例如取 β=1\beta=1β=1、两个模型给同一回答的概率分别为 0.040.040.04 和 0.010.010.01，则奖励为 log⁡4≈1.386\log4\approx1.386log4≈1.386。这反映模型学到的偏好，不保证回答客观正确。单独使用 DPO 模型的 log-prob 是另一种打分，并非上述隐式奖励。

9. 能否将它作为 PPO 的奖励

可以。缺少只依赖 prompt 的常数项不是障碍。在理想推导中令 c(x)=βlog⁡Z(x)c(x)=\beta\log Z(x)c(x)=βlogZ(x)、r^=r−c(x)\hat r=r-c(x)r^=r−c(x)，则固定 prompt 分布下：

Jr^(π)=Jr(π)−Exc(x),∇Jr^(π)=∇Jr(π).J_{\hat r}(\pi)=J_r(\pi)-\mathbb E_x c(x), \qquad \nabla J_{\hat r}(\pi)=\nabla J_r(\pi).Jr^​(π)=Jr​(π)−Ex​c(x),∇Jr^​(π)=∇Jr​(π).

传统 Bradley–Terry RM 也仅通过奖励差学习偏好，不能仅靠这类数据识别唯一的奖励零点。PPO 需要数值奖励，不要求恢复这个零点。

进一步定义价值基线 V(x)V(x)V(x) 为策略在问题 xxx 上的预期回报，优势 A(x,y)=r(x,y)−V(x)A(x,y)=r(x,y)-V(x)A(x,y)=r(x,y)−V(x) 表示“这条回答比通常预期好多少”。给所有回答的奖励都减去同一个 c(x)c(x)c(x)，准确的价值基线也会同步减去它。因此，把整段回答视为一个动作时：

A^(x,y)=[r(x,y)−c(x)]−[V(x)−c(x)]=r(x,y)−V(x)=A(x,y).\begin{aligned} \hat A(x,y) &=[r(x,y)-c(x)]-[V(x)-c(x)]\\ &=r(x,y)-V(x)\\ &=A(x,y). \end{aligned}A^(x,y)​=[r(x,y)−c(x)]−[V(x)−c(x)]=r(x,y)−V(x)=A(x,y).​

实际 token 级 PPO 的 GAE、价值估计误差、奖励预处理等会影响训练轨迹；不能据此声称两种奖励下每一步更新都数值相同。上述常数不变性针对固定 prompt、未额外引入长度相关折扣的响应级目标。

接入过程：

  1. PPO 策略生成回答；冻结的 DPO 与 reference 对该回答打分。
  2. 由奖励与价值估计构造优势；正奖励也可能低于预期，从而产生负优势。
  3. PPO 用当前策略与采样旧策略的 token 概率比执行 clipped 更新：
ρt(ψ)=πψ(yt∣x,y<t)πold(yt∣x,y<t),Jclip=Etmin⁡(ρtAt,clip⁡(ρt,1−ϵ,1+ϵ)At).\begin{aligned} \rho_t(\psi) &=\frac{\pi_\psi(y_t\mid x,y_{<t})}{\pi_{\rm old}(y_t\mid x,y_{<t})},\\[4pt] J_{\rm clip} &=\mathbb E_t\min\left(\rho_t A_t,\operatorname{clip}(\rho_t,1-\epsilon,1+\epsilon)A_t\right). \end{aligned}ρt​(ψ)Jclip​​=πold​(yt​∣x,y<t​)πψ​(yt​∣x,y<t​)​,=Et​min(ρt​At​,clip(ρt​,1−ϵ,1+ϵ)At​).​

这里 ψ\psiψ 是正在训练的 PPO 策略参数，πold\pi_{\rm old}πold​ 是采样这批回答时的旧策略，AtA_tAt​ 是 token 位置 ttt 的优势估计，ϵ\epsilonϵ 是裁剪范围。ρt\rho_tρt​ 衡量“同一个已采样 token 在更新前后变得多容易出现”；clipping 限制一次更新偏离旧策略过远。

这里有两种概率比：DPO/reference 用来定义奖励；PPO 当前策略/old policy 用于更新。PPO 另行使用的 KL 参考策略也必须明确配置，不应与这两个角色混用。直接最小化当前策略与 DPO 策略的 KL，更接近策略蒸馏。

“能够使用”不等于“值得再训练”：若使用同一个 reference、相同 KL 系数，并且从精确的 DPO 策略开始，则它已是这个隐式奖励目标的理想最优策略；再次优化该目标没有额外的理想收益。实际使用价值要看奖励质量、模型差异和训练设置。
