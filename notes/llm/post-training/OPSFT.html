来源：摘要与版本记录、v1 PDF、HTML 全文、官方代码。公式、图表和页码以 PDF v1 为准。代码解读对应 2026-10-13 核对的提交 5460fe1。

相关周报：2026-10-12 大模型周报中的 OPSFT 条目。相关基础：DPO、Pair-GRPO、混合精度。

核心结论与研究判断

论文最有价值的结果是：在相同教师轨迹上，保留 on-policy 训练识别出的逐参数更新位置与正负号，能让 SFT 的数学与代码泛化明显改善。 它把一部分 on-policy 训练的产物变成可复用的优化约束；损失函数仍是交叉熵，后续训练不必持续在线采样。

我的判断是，OPSFT 值得作为“已有 RL 或 OPD checkpoint 后，继续吸收优质示范”的基线。实验比单纯的参数相关性分析更进一步，因为作者实际干预了 SFT 的更新规则，并加入位置约束和随机符号对照。不过，这支持的是方向信息具有可迁移的作用，尚不足以证明它是所有 on-policy 泛化优势的唯一或必要原因。理论部分给出了梯度结构的解释，没有证明测试误差界，也没有证明 SFT 的方向必然固定。论文 §3–4、附录 C

梯度分析与它的证明边界

为什么当前策略下的 score 期望为零

给定 prompt xxx、完整响应轨迹 τ\tauτ 和参数 θ∈Rd\theta\in\mathbb R^dθ∈Rd，定义 score 向量：

on-policy 梯度是优势与 score 的协方差

使用轨迹优势 Aθ(x,τ)A_\theta(x,\tau)Aθ​(x,τ)，理想化的策略目标上升方向为：

对一个标量优势和一个向量 score，条件协方差本身是向量；论文文字称其为 covariance matrix 时，应按下面的对象理解：

Cov⁡(Aθ,sθ∣x)=E[Aθsθ∣x]−E[Aθ∣x]E[sθ∣x]=E[Aθsθ∣x],gon=Ex[Cov⁡(Aθ,sθ∣x)].\begin{aligned} \operatorname{Cov}(A_\theta,s_\theta\mid x) &=\mathbb E[A_\theta s_\theta\mid x] -\mathbb E[A_\theta\mid x]\mathbb E[s_\theta\mid x]\\ &=\mathbb E[A_\theta s_\theta\mid x],\\ g_{\mathrm{on}}&=\mathbb E_x[\operatorname{Cov}(A_\theta,s_\theta\mid x)]. \end{aligned}Cov(Aθ​,sθ​∣x)gon​​=E[Aθ​sθ​∣x]−E[Aθ​∣x]E[sθ​∣x]=E[Aθ​sθ​∣x],=Ex​[Cov(Aθ​,sθ​∣x)].​

因此对任意固定符号向量 vvv，v⊤gonv^\top g_{\mathrm{on}}v⊤gon​ 是该协方差沿 vvv 的分量。直观上，某个参数应往哪边走，取决于“该参数提高哪些当前响应的概率”是否与“这些响应获得的优势”一致。策略改变后，采样到的响应、优势和 score 都会变化。论文式 3–5，p.3–4

此处的符号需要注意：gong_{\mathrm{on}}gon​ 是策略目标的上升方向，而下一节的 ggg 是 SFT 损失的下降前梯度，实际位移近似为 −g-g−g。完整 GRPO 还涉及组内归一化、概率比与裁剪等，以上表达用于解释更新结构，不能代替完整实现。

固定教师数据不意味着 SFT 梯度恒定

固定教师分布 q(τ∣x)q(\tau\mid x)q(τ∣x) 下，SFT 最小化交叉熵：

LSFT(θ)=−ExEτ∼q[log⁡πθ(τ∣x)],∇θLSFT=−ExEτ∼q[sθ(x,τ)].\begin{aligned} L_{\mathrm{SFT}}(\theta)&=-\mathbb E_x\mathbb E_{\tau\sim q}[\log\pi_\theta(\tau\mid x)],\\ \nabla_\theta L_{\mathrm{SFT}}&=-\mathbb E_x\mathbb E_{\tau\sim q}[s_\theta(x,\tau)]. \end{aligned}LSFT​(θ)∇θ​LSFT​​=−Ex​Eτ∼q​[logπθ​(τ∣x)],=−Ex​Eτ∼q​[sθ​(x,τ)].​

教师轨迹分布固定，但 sθs_\thetasθ​ 仍随参数变化。故这些公式只解释了两类训练的驱动力不同，不能单独推出 SFT 的更新符号必然不变，或 on-policy 的方向必然近似正交。论文图 2 在 Qwen3-1.7B / DeepMath 上给出观察：SFT 区间更新正相关，累计方向余弦接近 1；OPD / GRPO 区间更新更接近正交，累计相关约 0.5。它是该实验下的数值现象。论文式 6、图 2，p.4

还有一个推理跳跃：动态方向探索之后，作者选取最终累计符号作为约束。动态调整有助于提出这个假设；最终符号能否保留泛化收益，真正由 OPSFT 干预实验回答。

OPSFT 的两级约束

从 checkpoint 差分提取支持集与符号

设原始基座为 θbase\theta_{\mathrm{base}}θbase​，on-policy checkpoint 为 θon\theta_{\mathrm{on}}θon​：

D=θon−θbase,Mi=1[Di≠0],vi=sign⁡(Di)∈{−1,0,1}.\begin{aligned} D&=\theta_{\mathrm{on}}-\theta_{\mathrm{base}},\\ M_i&=\mathbf 1[D_i\ne0],\\ v_i&=\operatorname{sign}(D_i)\in\{-1,0,1\}. \end{aligned}DMi​vi​​=θon​−θbase​,=1[Di​=0],=sign(Di​)∈{−1,0,1}.​

MMM 决定哪些坐标允许学习，vvv 决定这些坐标允许朝哪个半轴移动。官方主复现采用 exact nonzero support，差分精确为零的坐标被禁止更新。提取脚本也支持 top-k 和 threshold，但它们是不同的选择规则，不能默认为论文 exact-support 配置。方向提取代码

这个“非零”依赖 checkpoint 的实际存储精度。把 BF16 checkpoint 转成 FP32 后相减，不会恢复保存前已被舍入掉的微小更新；跨精度比较时必须同时记录训练主权重与保存精度。

第二层在 optimizer step 后投影累计位移

AdamW 的动量和解耦权重衰减可能绕过“当前梯度置零”。因此官方代码在更新后检查参数。设 θ0\theta_0θ0​ 是本轮 SFT 的初始权重，θ~\tilde\thetaθ~ 是 optimizer step 的临时结果，则：

这把参数限制到以 θ0\theta_0θ0​ 为顶点的逐坐标符号锥：

C={θ:θi=θ0,i 若 Mi=0;vi(θi−θ0,i)≥0 若 Mi=1}.\mathcal C=\{\theta:\theta_i=\theta_{0,i}\ \text{若}\ M_i=0;\quad v_i(\theta_i-\theta_{0,i})\ge0\ \text{若}\ M_i=1\}.C={θ:θi​=θ0,i​ 若 Mi​=0;vi​(θi​−θ0,i​)≥0 若 Mi​=1}.

这里约束的是相对初始权重的累计位移，不是每一步实际位移都必须同号。 一个正方向坐标可以从 θ0+0.2\theta_0+0.2θ0​+0.2 回到 θ0+0.1\theta_0+0.1θ0​+0.1，仍在合法半轴内。新梯度有方向过滤，但优化器状态可能使一步位移回退；硬投影只阻止它跨过初始点。核对的代码对违规坐标恢复参数，没有同时清空该坐标的动量状态。官方 trainer 的梯度过滤与参数约束

从几何上看，这是高维正交象限约束，允许各参数独立选择幅度；它不是把梯度替换成 αv\alpha vαv。因此逐参数符号固定，并不妨碍整层更新向量的余弦方向随训练改变，也不要求最终幅度复制 GRPO。这个区别解释了图 6 的矩阵级方向变化。

这是特定训练协议下的整段墙钟收益：不同方法更新次数、rollout 数和样本暴露量不同；减少的是持续采样需求与达到所报分数所需的训练时间，没有证明相同步数下 OPSFT 单步计算快两倍。论文时间表没有单列教师轨迹生产、数据筛选与评测成本；新建流水线时不能把训练时间当成完整端到端成本。

代码实验也有相同趋势：Qwen3-4B / Eurus 的三 benchmark 均分为 GRPO 57.19（20.3h）、SFT 54.30（9.8h）、OPSFT 58.07（9.5h）。OPSFT 对 GRPO 省时约 53.2%，对 SFT 仅约 3.1%；且 MBPP+ 的 67.30 低于 GRPO 69.04。表 4，p.8

普通 SFT 在 4B、8B 和 R1-Distill 上退化，1.7B 仍提升；因此“再 SFT 必然破坏 RL 能力”也过强。OPSFT 在四个均分上都提高，但并不保住每个单项：Qwen3-4B 的 AIME25 从 45.31 到 44.17。结论应是该设置改善了平均表现与继续学习稳定性，不能保证所有能力不退化。表 3，p.7

BF16 会舍入小位移，所以“只动 0.408% 参数”同时受约束和数值精度影响。论文所写相对基座“24.59% improvement”，由 40.94−16.35 得到，应读作 24.59 个百分点；若算相对增幅则约 150.4%。它也不等价于只需要为 0.408% 参数保存优化器状态：公开实现仍采用完整模型训练和约束张量，未给出与这个比例相称的显存节省。表 6、§4.3，p.8

谱分析图 A8 显示 OPSFT 更新的 stable rank、奇异值分布和主方向旋转更接近 GRPO；图 7 显示类似响应长度和部分推理提示词频率。它们是辅助机制观察，不能把更高输出方差或更多逻辑连接词直接等同于更强推理能力。

可复现入口与实现要点

官方仓库已经提供教师验证轨迹、匹配的 4B DeepMath 150 步 checkpoint 与模型集合。第一轮验证可以复用这些资产，检验 SFT 与 OPSFT 的差别；节约的是本轮重复采样与教师数据生成成本，方向本身仍来自已有 on-policy 训练。

复现顺序为：冻结基座与 checkpoint 的 revision → 提取 exact support / 差分 → 从同一初始模型跑 SFT、location-only、direction 三组 → 同一评测生成配置比较均分和单项。提速与继续学习使用不同 checkpoint 和初始模型，须按上面的协议表执行。

代码入口 实际负责什么
run_extract_subspace.sh 与 scripts/analyze_update_mask.py 加载匹配权重，保存 update_mask.pt、parameter_updates.pt 和统计
run_sft.sh 配置初始模型、数据、SFT_VARIANT、精度、步数与评测
verl/verl/trainer/fsdp_sft_trainer.py 加载分片 mask / 差分，反传后过滤梯度，更新后恢复违规参数
docs/application_efficiency.md 50 步方向识别与 100 步 OPSFT 的提速协议
docs/application_continual_posttraining.md 从 GRPO checkpoint 继续训练的协议

官方完整使用说明

实现时最容易出错的是梯度下降的负号、两种初始权重、优化器状态，以及分片张量与 mask 的对齐。还应记录每层允许坐标比例、过滤前后梯度范数、实际位移范数、更新后违规坐标数和精度。exact-support 检测里极小变化也会算作非零，checkpoint 存储变化可能影响整个约束。

公开提取脚本在 CPU 上同时加载两份 FP32 模型，并拼接全模型绝对差分；8B 的两个权重本体就约 64 GB，尚未计入差分、拼接副本和框架开销。训练还保留本轮初始权重和约束信息，不能把“多一个简单 mask”误读为几乎零内存成本。大模型应先评估共享路径上的内存峰值，再考虑按层流式提取。

局限与进一步实验

论文最明确的适用前提是强教师生成并通过验证的优质轨迹。附录 C.2 承认尚未系统处理轨迹质量、多样性与学生适配性；OPSFT 不能替代恢复轨迹、失败状态覆盖或高质量监督。

从机制判断看，现有证据还有四个边界。第一，固定 seed 42 与有限模型不能建立普适结论，小幅 OOD 差异需要多 seed 与置信区间。第二，符号依赖参数坐标、模型结构和精度，未证明可以跨模型直接搬用。第三，同号约束没有幅度上界，沿合法方向走太远仍可能损害能力。第四，成功轨迹上的收益不自动覆盖有噪声、负样本、多模态或长程交互设置。

复现优先级建议如下；这是基于论文证据提出的后续实验，尚未执行：

优先级 实验 想排除的替代解释
1 相同初始模型、轨迹、LR 和更新次数，SFT / location / true sign / random sign，至少 3 个训练 seed 单次随机性与任意 mask 正则化
2 匹配每层支持集、过滤梯度量和位移范数；加 SFT 自身差分符号作方向来源 收益是否只来自更小步长或通用训练符号
3 按 GRPO 10 / 25 / 50 / 100 / 150 步提取方向，画累计 GPU 小时与质量曲线 50 步是否适合当前任务，方向何时值得冻结
4 分别测试强教师、弱教师、噪声与恢复轨迹；固定最终评测集 数据质量是否决定 OPSFT 还能否有效
5 多轮追加数据、方向刷新、幅度或 KL 约束，记录逐任务退化 一轮继续学习收益是否能持续

若迁移到当前推箱子多轮 SFT，第一步应先补齐恢复示范与独立地图评测，再讨论从同一模型的 on-policy 阶段提取方向。论文验证的是全参数坐标，LoRA 的 A/B 因子有重参数化自由，A/B 符号并不等价于合并权重差分的符号；不能把 full-weight OPSFT 直接改成 LoRA 梯度符号过滤后声称同方法复现。

阅读总结

OPSFT 提供了一个值得检验的后训练分工：on-policy 阶段识别有用的更新坐标与符号，SFT 阶段用优质轨迹在允许的符号区域里学习更新幅度。其最扎实的证据是同数据下的真实符号干预，以及已有 GRPO checkpoint 后的继续学习收益。

对实际项目，先复用已有方向资产做同预算对照，比立即新跑大规模 RL 更容易判断收益。保留三个判断标准：看独立任务结果而非训练 loss；把方向识别、数据生产与训练成本分开记账；同时报告逐任务退化与均分提升。标题提出的是机制主张，当前结果最稳妥地落在“方向可转移部分泛化收益”这一层。
